# 一键导出并发布

下次需要发布时，双击本文件夹的 `双击发布.cmd`，等待窗口显示 `COMPLETED`。也可在 PowerShell 中运行 `./一键发布/release.ps1`。

脚本依次离线构建 JAR、复制到本机游戏实例的 mods、上传并替换服务器模组、重启并等待服务器启动，最后通过现有 Mods 同步器发布该实例的完整 mods 清单，供玩家同步。服务器重启会断开在线玩家。发布的是运行时本机 mods 目录中的所有 JAR，请先确认该目录内容。

需要本机已配置的 Java 25、Gradle、SSH 别名 `homo` 与免交互 sudo，以及 `temp/mod-sync/publish/YumisModSync.exe`。若同步器不存在，先根据 `ModSyncTemp/README.md` 和本机环境说明构建。脚本不携带或上传私有配置。

窗口显示 `FAILED` 时查看上方错误；流程会在失败处停止。若发布清单失败，游戏服务器可能已经更新，应修复错误后重新运行。发布报告和日志位于 `temp/one-click-release/`，服务器状态可用 `ssh homo "systemctl status yumis-minecraft --no-pager"` 查看。
