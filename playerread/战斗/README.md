# 战斗

近战、弓弩与三叉戟保留原版命中反馈，实际生命通过模组结算。直接伤害、附加伤害、护盾和异常状态按各自规则处理。

造成或受到有效伤害后，需要连续3秒未再交战才算脱战。受伤后装备护盾等待5秒再恢复，每秒恢复上限的20%；脱战生命每秒恢复2%，魔力恢复速度提高。

闪避值先转换为概率，30000对应75%；超出部分效率降低，最高90%。DOT、环境等不可闪避来源不按直接攻击处理。

伤害榜按本轮副本个人累计战斗时间计算DPS，退本或断线移除，重进清零，通关冻结。

## 伤害分析

按Ctrl＋】开始或停止本人统计，开始时清零并计时；按I打开角色界面，再点“伤害分析”查看。页面按总伤害排序，显示技能、伤害、占比、有效命中次数、总时长和DPS；关闭页面不停止记录。

实战只计确认的实际扣血，排除超杀与无效命中。普攻单列，装备附伤、流血和感电归触发技能。沙袋独立计算：与实战互换时自动停止并保留上一轮结果，需要再次开启。停止后仍可补记停止前已发出的有效命中。

换地图、维度、进入或离开副本以及断线会清空本轮；死亡停止并保留结果，复活不自动续记。

## 伤害数字

所有伤害点数、伤害榜与分析DPS统一四舍五入显示完整整数，实际结算与累计保留完整精度。

同一目标的新伤害数字排在下方，旧数字按实际字号向上让位；一列拥挤时向侧面分列，相邻目标的数字也会避让。每笔伤害独立显示，持续约1.1秒后消失。

暴击数字比普通数字放大50%，带金色描边，末尾增加一个感叹号；文字本体保留伤害的元素颜色。普通怪物和训练沙袋使用相同的显示方式。本人伤害数字倍率仍可在设置中调整。

相关：[属性](../属性/README.md)、[技能](../技能/README.md)、[副本与敌人](../副本与敌人/README.md)。

伤害权值与成长规则见[技能伤害权值](../技能/README.md#伤害权值)。

## 装备伤害与资源

天脊乾坤剑保留火强化，其他三种强化按33%转为火后清零；无元素伤害转火，混合元素含火时只保留火，不含火分量禁止。别云剑-无用禁止所有带元素标签的伤害分量，无元素物理和魔法伤害保留。

天脊的比例火伤以原主伤和固定附伤的最终合计为基数，不包含其他比例追加。追加继承主伤物理/魔法类型，再算对应防御和火强化/火抗；暴击、通用增伤、等级差等已有倍率不再重复计算，也不递归追加。

承伤先扣临时护盾，再扣装备护盾，之后按比例由魔力承担，剩余扣生命。1点MP抵1点伤害，MP不足余量扣生命，魔力承担比例最多生效100%。技能主动生命支付直接扣生命，不经过盾和魔力承担，必须至少留下1点，否则整次施放失败。

黄金之力在本人有效击杀后加1层，最多255层，每层掉宝率+1；新层从后续击杀掉落生效。印记之力在成功施放主动技能后加1层，最多18层，每层伤害提高1%，本次起手即可享受新层。两者连续20秒没有对应有效事件整组清除，满层触发也刷新计时；失败施法、普攻、被动触发和技能段数不加印记。HUD显示层数与剩余时间。

英雄王击败精英继承对应力量，持续时间由该件生成时确定；不同类型同时保留，同类型只刷新时间。上述装备BUFF均在卸装、资格失效、死亡或退出时清除。力量类型见[副本与敌人](../副本与敌人/README.md)，吸血换算见[属性](../属性/README.md)。
