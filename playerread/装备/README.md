# 装备

装备包括武器、四件防具和六类饰品。辅助装备、魔法石、耳环分别在50、60、70级启用，饰品槽由Curios提供。

制作器制作白装，目标等级不得超过角色等级。不同防具和首饰模板提供不同属性方向。尚未设计的史诗、神话版本没有开放。

装备升级通常每次提高5级，最高80级，保留身份、品质、锁定、孔位、宝石和套装。本版本装备在创建时保存基础成长曲线，主动升级沿这条曲线成长；后续模板调整不会替换已经保存的基础。

法师之血为独立60级神话护腿，仅在神话创造页提供，没有自然掉落。它的魔法和增幅不随升级成长，升级只提高穿戴门槛。

相关：[词条](../词条/README.md)、[经济与奖励](../经济与奖励/README.md)、[库存](../库存/README.md)。

## 武器属性查看

武器提示的“武器属性”区只显示计入本件词条和宝石后的物理攻击、魔法攻击，以及按元素汇总的固定附加伤害区间。属强、攻速等继续在基础与词条说明中查看，效果照常生效。按住左或右Shift查看加成前的基础数值和武器基础攻速，同时展开词条和宝石的可重掷范围；松开后恢复。词条、宝石和套装效果仍分别列出。

别云剑-无用的50%～100%物攻提高先作用于本武器，之后再加其200～400点最终固定物攻。整件武器结算结果再参加角色属性计算。已有本版本装备沿各条原随机位置同步到新范围，保留身份、基础成长、腐化倍率、孔位、宝石和加工投入。

## 武器外形

普通、稀有、神器、传说武器按类型共用立体外形：太刀参考流光星陨刀，光剑参考泰拉石光剑，巨剑参考天选之剑－格朗，短剑参考卢克西的紫炎波刃剑，钝器参考雷神之怒。不同等级段仍保留各自名称和属性。

标准版蓝色光剑的能量外层为半透明，能透出背景；亮色内芯、金属护手和剑柄保持实体外观。

天脊乾坤剑、别云剑-无用、威利的戒严法杖和尼巫的职责分别制作独立外形。天脊采用旧版橙金色造型；尼巫采用长棍／笛形的近似设计。首版模型已完成游戏内初步预览；第一人称保留原倾斜方向，右手武器稍向左移。此次外形调整不增加装备效果、套装或获取途径。

## 本批具名装备与获取

新13件装备仅在史诗/神话创造目录提供，尚未加入自然掉落：威利的戒严法杖、天脊乾坤剑、别云剑-无用、波利斯的黄金杯、罗塞塔石碑、英雄王的象征、尼巫的职责、时空之肌、鲜血誓言、芮兹的第六元素、华丽的小丑帽、皇冠、魔力流转。从创造目录取出时生成该件的独立随机数值。

无尽魔力之花是50级史诗辅助装备，仅在史诗创造目录提供。它使最大魔力增加4000～6000点、魔力回复速度提高200%～600%；两项各自随机。装备升级保留这两项的随机位置，神圣石和腐化沿用现有重洗规则。

史诗和神话创造目录只保留上述具名装备、无尽魔力之花和法师之血。其他通用史诗／神话停止自然掉落和创造目录投放；自然装备抽中这些品质时改为传说，掉落次数不变。已经获得的本版本装备仍可使用，并按原规则升级和重洗。

威利初始8孔，宝石数值效果提高200%～300%。尼巫的魔法技能加级与攻速已实现，炫纹相关标记“未实现”；当前无法获取炫纹。时空之肌授予闪现，装备授予规则见[技能](../技能/README.md)。技能页直接显示有效授予等级并允许绑定；穿戴资格失效时保留绑定和冷却，但不能施放。

棍棒使用3格物理近战。法杖发射不耗魔的无元素魔法弹，射程12格、每秒20格，首次碰撞敌人或方块消失。两者基础普攻间隔650毫秒，按攻击速度缩短，切武器不清空冷却；法杖技能释放速度−20%只影响技能动作。

首次选择魔法师时领取1级普通学徒法杖，仅此途径发放，不加入自然武器池；没有独特词条、套装或初始孔，沿用已有法杖基础成长。史诗和神话版本尚未设计、未投放。重置职业不补发，已有装备不会被替换。

系别加级词条恢复中文显示，例如“波动系技能 +1级”；原词条ID、加级与随机结果保持。魔法师新增的四系本次不进入随机词条池。

## 腐化

狄瑞吉之血使用后不可逆地标记腐化。变级、数值刷新、加1孔各自独立20%判定，可以同时发生，三项都未触发的概率51.2%，仍消耗通货并腐化。依次先变级、再刷新、最后加孔。

变级为−5～+5整数，包含0，装备最低1、最高85级；基础、穿戴需求和授予技能等级同步变化。普通升级仍最高80级。腐化保留已镶嵌宝石并继续生效，新镶嵌仍检查装备等级；威利可出现第9孔。

腐化装备允许穿戴、镶嵌或覆盖、出售、整件分解，禁止其他加工、提炼及再次腐化。可洗词条及刷新倍率规则见[词条](../词条/README.md)。

## 武器手持与词条

立体武器第一人称沿握柄长轴翻面，再向左前方偏约30°，左右手适配，刀尖上下方向保留；第三人称、背包、掉落与展示框姿态保持。固定附伤及平双攻变化见[词条规则](../词条/README.md#元素附伤与固定双攻调整)；装备身份、基础成长、孔位、宝石和玩家投入保留。

## 创造取装与手动丢弃

从创造目录取出的新装备，先确认进入玩家背包，再在下一游戏刻完成一次独立随机初始化；光标与目录预览不提前刷新。移动、重连或查看已有装备不会重新抽取属性。

创造模式主手拿模组武器时不能破坏方块。非创造模式不能用Q、Ctrl+Q或往背包外扔来直接丢弃模组装备；创造模式允许正常丢弃或删除。死亡、奖励掉落及[出售与分解](../经济与奖励/README.md#分解与无色小晶块)沿各自规则处理。

黄金杯、罗塞塔石碑、英雄王的象征、鲜血誓言、小丑帽、皇冠、魔力流转、无尽魔力之花，以及神话时空之肌和芮兹的第六元素更换专属图标；获取资格与效果保留。神话名称、品质字样及品质框采用上金下粉的配色，支持可选Modern UI提示框。
