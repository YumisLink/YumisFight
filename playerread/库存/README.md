# 库存

I菜单内可以打开次元背包。背包从8格逐档升级至416格，使用九列滚动视图，支持搜索、整理和升级。

本次使用新的背包数据，不合并旧版本存档。装备扩槽移除时，物品进入等待领取，可通过领取功能取回。

通货拿在鼠标光标上，右键真实装备槽加工。成功消耗1枚，失败不消耗、不交换物品。镶嵌覆盖会损失旧宝石，套装提取消耗来源装备。

相关：[装备](../装备/README.md)、[经济与奖励](../经济与奖励/README.md)。

普通背包与次元背包的“出售装备”入口会定位I菜单同级出售Tab，多选及保护规则统一见[经济与奖励](../经济与奖励/README.md)。宝石提炼、覆盖与腐化加工限制见[装备](../装备/README.md)和[词条](../词条/README.md)。
