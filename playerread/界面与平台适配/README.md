# 界面与操作

安装本模组的专用服务器启动时会开启 `allow-flight`，避免技能悬空被原版飞行检测误踢；这项设置本身不会授予玩家飞行能力。

恶魔猎手与浩劫的原魔力栏改为绿色怒气栏，角色属性页也显示怒气并隐藏魔力恢复；献祭光环在右侧使用持续时间量谱，眼棱在读条位置显示反向进度，名词见[显示与演出术语](#显示与演出术语)。切换到使用魔力的职业配置后恢复魔力显示。资源规则见[恶魔猎手怒气](../角色与转职/README.md#恶魔猎手怒气)。

按I打开模组菜单，按G打开Curios饰品界面。原版E背包也有饰品入口。

普通E背包的配方书右侧有同尺寸的角色头像按钮，悬停显示“角色面板”，点击打开与I键相同的模组主菜单，可继续进入角色属性、职业技能等页面。配方书展开、收起时按钮跟随背包位置移动。

六类饰品空槽使用统一灰色像素轮廓：项链、手镯、戒指、护手形辅助装备、晶体形魔法石和耳环，放入装备后显示物品图标。

角色属性页增加“伤害分析”入口；Ctrl＋】只控制开始／停止统计，查看方式和清理规则见[战斗伤害分析](../战斗/README.md#伤害分析)。

按C使用梯云纵；按住当前跳跃键再按C可强力向上跃起。可以空中连用，受体力和间隔限制；落地后按规则恢复体力。

界面可在灰色立体与黑灰透明之间切换，操作布局相同。默认I面板使用黑灰透明，其余为灰色立体。I设置页可改变统一主题，并选择I面板、机器面板是否跟随；关闭跟随会保留当前样式，之后可单独切换。设置立即保存到本机。机器面板包含工业设备及其配方/结构/概率、制作器和次元背包。稀有度、属性颜色与战斗HUD颜色保留。

黑灰透明主题的面板、卡片和按钮采用更深的近黑底色，悬停与选中仍有明暗区分，文字保持原有亮度。

背包等容器中的装备和通货采用品质底框，品质线框四边各向内缩1像素。普通、稀有、神器、传说、史诗使用白、蓝、紫、粉、橙配色，神话品质框上金下粉；物品图标大小与格子间距保持原样。创造背包的边框在悬浮详情下方绘制。神话装备名称与品质字样同样上金下粉，属性说明保持原色，安装Modern UI时提示框也使用相同方向的配色。

I菜单增加同级“出售”Tab；次元背包的“出售装备”按钮也会直接定位它。普通E背包底部的出售／分解快捷按钮已移除，可从角色头像按钮打开菜单后进入“出售”。出售、保护和确认规则见[经济与奖励](../经济与奖励/README.md)。商城可购买霸王之契约。

I菜单新增“词条”宝典，支持搜索、部位和收藏筛选，具体规则见[词条](../词条/README.md#词条宝典与收藏)。出售页可切换分解，商城显示无色小晶块余额，规则见[分解与无色小晶块](../经济与奖励/README.md#分解与无色小晶块)。

I菜单内的文字与卡片页面统一留出顶部空白，角色属性首行、技能页的剩余SP和未选职业时的“选择基础职业”等内容不再紧贴内容框顶边。未选职业时可在技能页[选择基础职业](../角色与转职/README.md)，职业卡片随页面宽度自动换行；转职选择位于技能页底部，独立转职Tab删除。技能快捷栏、按键及咏唱条的位置见[技能操作](../技能/README.md)。屏幕右侧集中显示刻印、血剑、续段以及破极兵刃、卡洛、暗天波动眼和赫尔德的剩余时间量谱；具体持续时间见[技能](../技能/README.md#持续时间量谱)。普通攻击剑光的淡出更缓；伤害基准见[技能权值](../技能/README.md#伤害权值)。

设置中的本人伤害数字倍率同时影响普通与暴击数字，暴击样式和堆叠方式见[伤害数字](../战斗/README.md#伤害数字)。

## 显示与演出术语

| 名词 | 含义 |
|---|---|
| 读条 | 咏唱时使用的横向进度条，通常从0向满格填充。 |
| 反向读条 | 沿用读条样式，从满格向0递减，表示这次引导或动作还剩多久；眼棱使用这种展示。 |
| 量谱 | 屏幕右侧按顺序排列的技能图标、名称、剩余秒数或层数及比例条；献祭光环与其他持续技能使用同类量谱。 |
| 拖尾 | 沿角色已经经过的路线留下短暂残迹，再逐渐消散。 |
| 连续挥动 | 多段攻击期间武器按各刀节奏持续挥动，双刀按左右手交替。 |
| 固定视角 | 镜头固定观察战斗区域，角色瞬移和穿斩不会带着镜头移动。 |
| 完全隐藏 | 等待期间人物、装备、名字、火焰、阴影与附身外观一起消失；技能地面范围可继续显示。 |

## 第一人称近身特效淡化

I菜单的“设置→战斗显示”可切换“第一人称近身特效淡化”，默认开启，立即生效并保存到本机。只在第一人称处理实际镜头附近的技能演出：距眼睛0～0.60格的部分隐藏，0.60～0.85格逐渐恢复，球外照常显示；移动镜头或切换视角时持续更新，不会删除技能或改变命中。

自己、队友和敌人的光效、光束、爆炸、轨迹、小粒子、幻影剑和技能飞剑均适用。角色、召唤物本体及正常手持武器照常显示；第三人称、工业连线、门户及原版和其他模组特效沿用原表现。大型火球若包住镜头，0.85格外的球壳仍可能遮挡视线，本设置不把整团特效变透明。

[日冕的外围虚化](../技能/日月魔法师.md#技能)是独立技能表现，不由这个开关控制。

客户端和服务端需要安装匹配版本的模组及Curios。JEI为可选客户端配方浏览工具。

角色属性与技能页左侧均列出[职业配置](../角色与转职/README.md#职业配置)，首次转职前显示解锁提示；解锁后支持独立滚动、切换与改名，窄屏移到页面正文。原左侧“职业减伤”文字移除，减伤效果保持。
