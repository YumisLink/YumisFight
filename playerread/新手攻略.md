# 新手攻略：从练级到觉醒

写给刚来到这个世界的旅行者：从出生村的七课引导，到亲手做出一身好装备，最后在50级完成觉醒。按顺序读下去，就是一条完整的成长路线。

## 一、开局：出生村与七课引导

出生村是一切的起点。找到引路人**伊蕾娜**，对话接取「旅途指引」，共七课；每一课都在 **I 菜单的任务追踪器**里提交，完成后自动接上下一课。

| 课程 | 做什么 | 提示 |
|---|---|---|
| 第一课 · 选择你的道路 | 在 I → 职业技能页选择基础职业 | 鬼剑士、魔法师、恶魔猎手三选一，**选定后不能更换**；首次确认分别领取 1 级太刀、学徒法杖或战刃 |
| 第二课 · 学会第一招 | 花 SP 学习第一个技能 | |
| 第三课 · 把本领放在手边 | 把主动技能绑到快捷栏 | 普通 / Ctrl / Alt 三层，每层 8 格 |
| 第四课 · 试试身手 | 打一场练习战斗 | |
| 第五课 · 一点成长 | 在属性页投入自由属性点 | 按住 Shift 一次最多投 5 点 |
| 第六课 · 亲手制作 | 用装备制作器做一件装备 | 例：1 级战靴＝4 哥布林布＋4 铁锭；制作目标等级不能超过角色等级 |
| 第七课 · 拾取魔能水晶 | 从地上拾取任意阶魔能水晶 | 完成送一组 3 阶魔能水晶和魔能储物袋，机器和魔王祭坛都靠它供能 |

升级会获得成长资源：每级 **2 点自由属性**（力量／智力／精神）和 SP（20 级前每级 15，20～29 级每级 25，30～39 级每级 40，40 级起每级 65）。SP 总量有限，学习技能前先想清楚流派。

## 二、练级：从野外到十五座副本

**1～10 级**：在野外打怪即可积累经验，很快就能到达。

**10 级起**：按 I 进入「副本」页。副本按等级一路排开，跟着自己的等级往上爬：

| 等级 | 副本 | | 等级 | 副本 |
|---:|---|---|---:|---|
| 10 | 哥布林营地 | | 45 | 月光酒馆 |
| 15 | 龙人之塔 | | 50 | 迷乱之村哈穆林 |
| 20 | 城主宫殿 | | 55 | 追击歼灭战 |
| 25 | GBL教会 | | 60 | 海上列车 |
| 30 | 天帷禁地 | | 65 | 时空之门 |
| 35 | 暗黑城入口 | | 70 | 谜之觉悟 |
| 40 | 斯卡萨的巢穴 | | 75 | 格兰迪发电厂 |
| | | | 80 | 魔女之森 |

每张图有**普通／冒险／勇士／王者／地狱**五档难度（白、蓝、紫、橘、红）。王者级敌人生命×4、攻击×2.1；地狱级生命×6、攻击×3。日常练级打普通～勇士就够了，转职试炼会要求王者级。副本结算给经验、金币、装备、区域材料（做装备用），每次击杀还有 5% 概率额外掉通货；掉宝率属性影响通货品质。可以组队，敌人属性随队伍人数成长。

**20 级转职**：在任务追踪器接「转职试炼」——通关王者级的哥布林营地、龙人之塔和城主宫殿，再触碰一次魔王祭坛，然后回职业技能页选择进阶职业：

| 转职 | 主要攻击属性 | 职业防护 | 一觉称号 |
|---|---|---:|---|
| 剑魂 | 物攻、力量 | 65% | 剑圣 |
| 鬼泣 | 魔攻、智力 | 50% | 弑魂 |
| 阿修罗 | 魔攻、智力 | 25% | 大暗黑天 |
| 狂战士 | 物攻、力量 | 75% | 狱血魔神 |
| 神谕代行者 | 物攻、力量 | 65% | 神谕代行者 |
| 召唤师 | 魔攻、智力 | 35% | 月蚀 |
| 日月魔法师 | 魔攻、智力 | 35% | 日冕 |
| 浩劫 | 物攻、力量为主，部分技能用魔攻、智力 | 65% | 浩劫恶魔猎手 |

没有通行任务杀敌或交材料的旧流程；也可以使用一次性转职解锁券（商城 500 点券，点券由管理员发放）直接取得资格。首次转职后解锁**职业栏**，可以保存多套职业配置分别养成。

**练功房**（副本页内）：金币练功房、通货练功房定向刷金币和通货；通用练功房的敌人同步你的等级，每波 12 只，约一成概率出精英（生命×3），经验按四分之一结算，适合挂机刷级；每个副本还有对应的材料练功房，按等级解锁，专门刷该副本的区域材料。

**训练沙袋**：工作台用 3 块任意羊毛＋1 干草块＋1 橡木台阶合成。放在地上随便打，出伤害数字但不会死，适合练手法；手持沙袋 Shift＋右键地面开启 20 秒 DPS 测试（Shift＋Alt＋右键为 60 秒），左上角伤害榜显示累计伤害和 DPS，用来对比装备和加点改动。

## 三、做装备：从白装到传说

装备共十一个栏位：武器、头盔／胸甲／护腿／战靴四件防具，以及手镯、项链、戒指等六类饰品；辅助装备、魔法石、耳环分别在 50、60、70 级启用。

**制作白装**：放置装备制作器并右键打开，选择部位、模板和等级即可制作，目标等级不能超过角色等级，消耗副本区域材料加常规材料（例：1 级战靴＝4 哥布林布＋4 铁锭）。不同模板属性方向不同。

**品质加工**：副本里掉落的加工通货可以把白装一步步顶上去，每一步追加一条随机词条：

```
普通 --蜕变石--> 稀有 --增幅石--> 神器 --富豪石--> 传说 --至臻石--> 继续补词条（上限六条）
```

**词条处理**：
- 神圣石重洗数值（高级、完美神圣石的数值下限更高）；混沌石随机删一条换一条；剥离石随机删一条；裂解珠把传说装备的一条词条锁定，防止被删换。
- 按 I 打开「词条」页查**词条宝典**：按部位浏览所有可随机出现的词条，点星星收藏，之后洗词条时命中的词条会显示星标。

**宝石与打孔**：打孔石给装备加孔（有上限），宝石镶嵌提供额外属性；同件装备不能镶重复效果的宝石，覆盖会销毁旧宝石。

**升级与腐化**：升级石每块提高 5 级，上限 80，词条、宝石、孔位全部保留（史诗、神话有专用升级石）。狄瑞吉之血是一次性腐化：变级（−5～+5）、数值刷新、加 1 孔三项各 20% 独立判定，腐化后不可逆，之后只能继续镶宝石——留到装备毕业前再赌。

**出售与分解**：I 菜单「出售」页可批量出售换金币，同页切「分解」换通货：普通装备出无色小晶块，稀有出蜕变石，神器在增幅石／狄瑞吉之血／打孔石中随机，传说在富豪石／混沌石／升级石中随机，史诗、神话各出专用升级石。用不上的装备别扔，分解是通货的主要来源之一。

**两个实用的进阶项**：
- 商城的**霸王之契约**（100000 金币／7 天）让穿戴等级要求放宽 5 级，可以先人一步穿高级装备。
- **大师水晶**给装备追加一条大师词条，觉醒任务的每个阶段都会送一个。

自然掉落的装备最高到传说品质；具名史诗／神话目前只在创造目录提供，正常游玩不必强求。

## 四、觉醒：50 级的四阶段试炼

达到 50 级后与伊蕾娜对话接取觉醒任务，进度在任务追踪器里查看。任务分四个阶段，每完成一阶段获得大师水晶 ×1：

**1. 祭坛献礼**：在魔王祭坛讨伐五位祭坛首领，集齐材料后**站在祭坛旁**提交。

魔王祭坛是工业祭坛方块，放入魔能水晶供能。先在祭坛用材料加工首领信物，再手持信物右键祭坛解锁、花费魔能召唤（例：无冠园丁信物＝2 魔力花＋1 枯灌木＋2 萤石粉＋800 魔能，召唤另耗 1600 魔能；其余信物配方可在 JEI 查询）。

| 首领 | 等级 | 评级 | 讨伐次数 | 每次掉落 |
|---|---:|---|---:|---|
| 无冠园丁 | 30 | C | 5 | 光苔接穗 |
| 歇工的圣母 | 35 | C+ | 4 | 圣札铜簧 |
| 白圣髑 | 40 | B− | 3 | 遗咏晶核；首次通关额外掉未竟圣页 ×1 |
| 催账人 | 45 | B | 3 | 停表齿轮 |
| 坠鳞的君王 | 50 | B+ | 1 | 余火硬鳞 |

合计需要：光苔接穗×5、圣札铜簧×4、遗咏晶核×3、未竟圣页×1、停表齿轮×3、余火硬鳞×1。

**2. 千室告解**：材料提交后，召唤并击败 55 级 A− 的祭坛首领「千室告解」。

**3. 登塔试炼**：到野外寻找塔门与石碑，进入觉醒塔。共有根系、锻炉、水闸、沙市、霜、星仪、封印、剧场八座主题塔，都是 50 级试炼，通关任意一座即可。

**4. 回村交谈**：回到出生点与伊蕾娜交谈，觉醒成功。

觉醒后职业头衔变更，并可以在职业技能页花 SP 学习本职业的一觉大招（即各转职的 50 级技能，通常 275 MP／90 秒冷却量级，每级 100 SP）：

| 转职 | 一觉技能 |
|---|---|
| 剑魂 | 极鬼剑术·暴风式 |
| 鬼泣 | 第七鬼神：邪神之怖拉修 |
| 阿修罗 | 暗天波动眼 |
| 狂战士 | 魔狱血刹 |
| 神谕代行者 | Furioso-Replica |
| 召唤师 | 契约召唤：征服者卡西利亚斯 |
| 日月魔法师 | 悖论 |
| 浩劫 | 恶魔变形 |

替代路线：商城 1000 点券出售一次性觉醒券，50 级使用直接取得觉醒资格，无需讨伐；但一觉技能仍要靠 SP 自学。

## 五、觉醒之后

- **引路石**：满级后的核心循环。引路石标注「地狱 +N」阶级、目的地和副本词条，放入野外引路台报名（最多 8 人），全部准备后开战。怪物从 81 级起步逐阶变强，完成速度决定返石阶数，每次死亡罚时，按阶结算分阶宝箱。阶级会一路上涨，是检验装备与手法的试金石。
- **方舟战争**：报名制的回合大战，派出自己的阵容参战，赢取方舟币。
- **副职业**：采药、钓鱼、炼金三条生活线（I 菜单「副职业」页），采集品有品质区分，炼金能熬出实用的药水。
- **工业**：从魔力花农场、发电机起步，搭传送带和液体管道组成产线；不少机器还能直接生产通货，是刷材料的另一条路。
