# 词条

词条的名称和说明用于展示，实际效果由规则决定。固定值、百分比、技能等级和特殊效果有不同加工资格。

神圣石重掷允许重洗的数值；锁定防止删除和替换，但不阻止允许的数值重洗。技能系等级不能被神圣石重掷，未锁定时可被混沌石替换。法师之血有独立重洗规则。

随机词条按装备部位和已有属性决定资格；显示名称不参与效果判断。

## 词条宝典与收藏

按I打开“词条”页面，可以搜索普通装备能随机刷出的属性、元素附伤和技能等级词条，点击星星收藏，也可只看收藏。点击部位按钮可只看武器、胸甲、头盔、护腿、战靴、手镯、项链、戒指、辅助装备、魔法石或耳环能出现的词条；“全部部位”清除部位限制。部位筛选可与搜索和收藏同时使用。宝典不列法师之血魔法、具名固有效果或停止投放的词条。

收藏后，装备、宝石和词条刷新结果中匹配的词条会显示星星；出售详情也会显示。收藏在本机保存，换角色、世界或服务器仍共用，只改变文字展示，不改变抽取概率、数值或实际效果。

本次更新中的词条同步采用“定义更新、装备保留”：在本版本中生成的装备保留原抽样位置；之后调整随机范围时按同一位置更新。例如原范围10～20、数值18，改为20～40后对应36，不重新抽取。当前格式中来源不能确定的词条保留原效果。

停止投放的词条不会从当前装备上消失。名称和说明更新不改变随机结果；技能等级、技能参数和法师之血按各自规则处理。装备的身份、锁定、孔位和宝石保留。

规则更新后，在线面板刷新；离线装备下次读取时同步。已经开始的技能使用开始时的参数。加工界面提示规则变化时，刷新后重试。

旧版本存档不继承，见[首页](../README.md)。以上为当前待发布更新的说明，具体发布情况见[更新目录](../更新/README.md)。

## 技能等级词条

技能等级词条均为+1～3级，按武器类型进入随机池，掉落、制作和加工追加／替换共用下表范围；词条宝典也按相同范围展示。

| 技能词条 | 可随机生成的武器 |
|---|---|
| 剑术、鬼神、波动、血气 | 鬼剑士武器：太刀、光剑、巨剑、短剑、钝器 |
| 日月、召唤、元素 | 魔法师武器：法杖、魔杖、棍棒、扫把、矛；扫把仍须尚未开放的精通才能有效使用 |
| 浩劫 | 战刃 |
| 魔法、物理、被动 | 所有武器 |

噬灭、复仇系词条预留给战刃，对应技能尚未实现，目前不投放，也不列入词条宝典。

以上随机技能加级共同占用一个名额：新生成或加工追加的装备最多随机出现一条，不因锁定而增加名额。已有当前格式装备保留原词条和实际效果，跨武器类型的已有词条也不会被删除或重抽。

日月系提高已学会的日月魔法师技能，也包含转职自带的日月流转；召唤系包含赫尔德及召唤师技能。被动技能加级提高已学会的被动，也包含日月流转。魔法系和物理系依技能实际采用的攻击类型生效，日月流转不接受这两类加级，也不接受装备独有的魔法技能加级。不能靠普通加级直接学会未学习的技能。通过不同有效来源获得的加级可叠加，召唤物和已开始的技能仍保留起手等级。

元素系沿用现有元素技能归属，包括杰克爆弹及日月魔法师技能；浩劫系包括已实现的恶魔猎手基础与浩劫技能。加级只提高已获得的技能等级，不绕过职业、学习或觉醒资格。

## 本批重洗与宝石

神圣石对所有品质的明确可洗区间生效，保留类型和固定数值。锁定仍只保护删除/替换。腐化触发数值刷新时，先重洗，再给每条可洗效果独立乘80%～140%；负值直接相乘，同条关联数值共用倍率。固定数值、技能等级、孔数、层数上限和规则开关不乘。以后更新词条区间时，原随机位置与独立腐化倍率同时保留。

皇冠加1枚词条拆解石，固定销毁整件并获得“皇冠之石”：角色经验获取提高10%。华丽的小丑帽同样固定产出“小丑之石”：掉宝率+15。宝石等级取来源装备当前等级，仅可镶嵌防具；拆解石仅创造获取。其他装备暂不开放此提炼。

提炼会销毁来源装备中已镶嵌的宝石，确认页会显示结果。同件装备不能镶嵌重复效果宝石；覆盖销毁旧宝石，不能取回。装备原生词条不占宝石重复效果名额。

固定附伤写作“附加X～Y点火属性伤害”。天脊的结算后比例追加单独计算，见[战斗](../战斗/README.md)，两者不会混为同一个效果。

## 元素附伤与固定双攻调整

四系随机附伤、通用史诗暗附伤与通用神话四系附伤，区间统一降到原来的25%；之后按[固定元素附伤规则](../战斗/README.md#固定元素附伤)计算技能倍率。天脊的结算后比例火伤不在本次数值削减范围。

固定物理攻击、固定魔法攻击词条按装备等级提高到接近削减后单条随机附伤的平均显示点数，1～8级保留原值。基准值20级约9.27、60级约49.02、80级约80.15点，再应用原随机品质与腐化。双攻还会受力量或智力影响，显示点数接近不代表实际伤害相同。武器本体基础双攻、百分比双攻及具名独特加攻不纳入这次提高。

当前格式沿原来源和随机分位同步，不重抽；宝石按自身等级处理。来源不明实例保留快照。
