# 队伍

I菜单队伍页只展示当前可用的操作。无队时可创建队伍或邀请玩家；无队邀请会在验证目标后自动建队。队伍通过邀请加入，已移除主动申请。

收到邀请后，在未交战、未施法且没有容器操作时弹窗接受或拒绝。邀请5分钟有效，接受前再次核对队伍和成员状态，已有队伍时不能加入另一队。

队长可邀请、移交、移除成员和解散；单人队隐藏移交和移除。普通成员可离队，队长多人队离开前须移交或解散。队伍人数不限，成员选择弹窗可翻页。GUI大小2每行4项，大小3按宽度排列。

进入公开副本的匹配与个人同步见[副本与敌人](../副本与敌人/README.md)。
