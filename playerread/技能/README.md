# 技能

按I打开技能页；未选基础职业时先[选择鬼剑士或魔法师](../角色与转职/README.md)。鬼剑士每个转职有7项专属技能，加上鬼斩、三段斩、地裂波动剑，共10项；魔法师有下述4项基础技能。学习消耗SP，按住Shift可最多连续学习5级；已学或有效装备授予的主动技能可绑定到普通、Ctrl、Alt三层快捷栏，每层8栏。被动不占快捷栏。底部快捷栏使用放大图标，冷却秒数叠在图标中央。

## 学习与快照

技能取消固定等级硬上限，从解锁等级学到1级后，人物每升5级可再学一级，仍消耗SP。20/25/30/35/40/50级技能每级消耗30/40/50/50/60/100 SP。人物上限仍为80级，SP总量不变，需要选择加点。普通技能加级要求已经学习；装备明确授予的技能按来源规则生效。

下表MP为技能1级消耗，伤害以技能页实时预览为准。伤害每级成长12%，MP每级成长8%；冷却、持续时间、范围、控制时长、生命成本和回复比例不随等级自动增长。伤害点数统一四舍五入显示整数，实际结算保留完整精度。

起手固定技能等级、属性、资源和参数。换装与规则更新不改变已经开始的施法，下一次施放才使用新值。释放速度缩短适用动作、蓄力和连击间隔，保留段数、位移总距离、冷却、BUFF及持续场时长。

主动职业技能在起手时检查主手：魔法师需要有效法杖或棍棒，鬼剑士及分支需要有效太刀、光剑、巨剑、短剑或钝器；光剑保留剑魂资格限制。换装不会取消已经发出的攻击或赫尔德。装备授予技能和职业被动沿用自身条件。

技能获得施放确认后，附近玩家各自在本机连续播放剑气、飞行波、冥炎和残影；实际命中仍由施法者计算并提交校验。三段斩、猛龙断空斩需在续段窗口内再次按原技能键，量谱显示剩余段数；修复首段过早结束不改变既有续按操作。

极鬼剑术·暴风式使用已有立体模型的太刀、光剑、巨剑、短剑、钝器，以及天脊乾坤剑、别云剑、威利法杖和尼巫棍棒组成24把视觉武器。本人和旁观者看到同一套排列，视觉阵列不产生可拾取装备。

## 伤害权值

以60级、120秒为基础标尺：**120秒目标伤害＝最终攻击面板×120×基础权值×技能权值×解锁档位倍率**。默认基础权值仍为0.5，最终攻击面板包含力量或智力换算。

伤害技能按自身解锁等级增强：**倍率＝10−7×（解锁等级−1）÷49**，最低3倍、最高10倍。1级技能10倍、5级约9.43倍、10级约8.71倍、20级约7.29倍、25级约6.57倍、30级约5.86倍、35级约5.14倍、40级约4.43倍、50级及以上3倍；人物升级不会降低已学低阶技能的这个倍率。普攻统一按最低阶提高10倍。

这次倍率作用于技能自身伤害、持续伤害、资源增量和终结；非伤害BUFF比例、MP、冷却、范围与装备固定附伤本身保持原值。面板1000时，1级解锁、权值1的技能在120秒参考窗口目标为600000；50级解锁、权值10的一觉为1800000。下表保留原始权值，实际参考贡献还需乘解锁档位倍率，低阶技能占比随之提高。

标尺按各技能独立时间轴、自然可学等级、零防零抗、非暴击、无装备附伤计算，只计120秒内实际发生的伤害。刻印按3枚、血刹按15层、增益按覆盖率、狂战士按双刀40%生命。剑魂各武器的加段、增伤和精通伤害计入权值；实际装备的技能加级、攻速、减冷却和附伤仍会增强输出。

### 赫尔德

有效技能1—4级只敲击，5级解锁投石，10级每轮对同一目标连续投3颗石头；有效等级包含装备加级。无加级时，人物30级、55级分别达到这两个阶段。

优先打召唤者正在攻击的敌人，否则寻找16格内最近敌人。近处2格内敲击，基础间隔1.2秒；投石基础冷却4秒，三连间隔0.2秒，就绪时优先投石。攻击间隔继承召唤时攻速；敲击与单石基础伤害比例1∶1.2。跟随主人，超24格或卡住时回到附近安全地面；攻击建立普通仇恨，不强制嘲讽Boss，与玩家和队友互不造成伤害。

召唤时固定有效等级、攻击伤害和装备附伤；继承召唤者200%生命及双防、150%四抗及闪避值、100%护盾与输出/攻速/移速属性，再按现有公式计算。闪避值倍率不等于闪避概率。各次攻击独立暴击，命中时再计算敌人的防御和抗性；能附加伤害，不触发“玩家攻击时……”效果，不递归附伤，伤害和击杀归主人。

赫尔德有独立生命和护盾，可以死亡，不耗自己的MP、不继承玩家吸血、MP分担或受击触发效果，也不脱战回血；自身受击5秒后，护盾每秒恢复上限20%。主人死亡、离线、换维度、重置职业或退级召唤技能时清除，重新召唤才更新属性。

### 持续时间量谱

破极兵刃30秒、卡洛20秒、暗天波动眼20秒、赫尔德120秒的剩余时间集中显示在右侧量谱：图标、技能名称、剩余秒数与比例条按顺序排列，到期或提前结束后移除。刻印数量、血剑积累和续段量谱继续保留。

## 控制与消耗

上述新技能对普通怪正常控制，精英硬控时长减半；Boss免硬控、免搬动，仍正常承伤并可触发嗜魂回血。墓碑、不动的引导被中断后，剩余段数取消，已支付资源不返还。

技能生命成本不扣护盾、不触发受击效果、不计入伤害榜。支付后必须至少保留1点生命，不足时整次技能失败，MP和冷却也不消耗。低血强化按支付后的生命确定。

鬼阵和冥炎持续伤害不独立暴击，不重复触发装备附伤或命中效果。死亡、离线、换维度、重转清除相应职业效果和资源。

崩山击、崩山裂地斩在角色实际落地后触发砸地伤害和特效；从空中施放时会继续下落，崩山裂地斩的后续喷发从落地点开始。

波动刻印在头顶小圈环绕，枚数显示在屏幕右侧的技能量谱，耗印和重新产印时同步变化。卡洛附身显示在角色身后。

## 装备授予技能与闪现

装备授予技能无需SP，不永久写入已学技能。基础等级为“来源装备当前等级÷5向下取整，最低1级”，80级装备授予16级，之后应用有效的魔法技能加级。武器主动技能默认右键；其他装备技能可在技能页装配，页面直接显示有效授予等级。无有效来源时不能新绑定；闪现可空手使用。卸装后保留绑定和剩余冷却，缺少有效来源时不可使用。

时空之肌授予主动魔法技能“闪现”：水平向前最多5格，从远到近寻找有支撑、无碰撞、无液体的合法位置，不能穿墙，最终三维位移最多5格。失败不扣资源、不进冷却。1级冷却8秒，此后每级减少0.1秒；1级20MP，每级魔耗增长8%，采用技能页取整值，再按[属性规则](../属性/README.md)计算冷却。

闪现属于魔法技能，不属于基础三技能，剑魂转换和基础技能套装不会将其误算为基础攻击技能。尼巫的炫纹附身仍未实现，当前不提供可用技能。

## 技能卡片与退级

技能页每行4张卡片，依次显示图标、名称、SP学习等级和学习按钮；悬浮可查看有效等级。左键图标绑定主动技能，学习按钮投入SP；右键卡片退1级，Shift右键最多退5级，不足5级退到0，返还实际减少等级的SP。

退级采用[脱战条件](../战斗/README.md)，只减少学习等级，装备加级及授予等级不返SP。每次退级结束该技能自己的阵法、附身、刻印、蓄血或增益；其他技能、冷却和已发出的攻击保留。完全失去使用资格时清除该技能绑定。装备专属技能不可通过退级返SP。
