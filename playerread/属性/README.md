# 属性

装备、角色成长和其他来源共同决定最终属性。界面按整数显示，内部计算保留小数。

“提升”和“最终提升”属于同一类加算倍率；标为“总增”的效果分别相乘。额外固定值和最终固定值按说明进入各自阶段，不能仅根据显示文本判断效果。

暴击率最高100%。掉宝属性影响掉落品质权重，不增加掉落次数。精神产生的魔力与魔防在其他倍率结算后加入。

相关：[装备](../装备/README.md)、[战斗](../战斗/README.md)。

本次整理了属性来源的汇总方式，现有乘区与计算精度保持；装备、职业和特殊效果按各自来源汇总。

## 吸血与资源倍率

吸血值换算吸血率：先把超过1000/19的部分按1/3效率折算，所得数值除以“1000＋该数值”，最高90%。仅普攻、技能直接伤害及其附伤按实际扣除的敌人生命回复，超杀、持续伤害和反伤不计。

魔力回复速度、冷却恢复速度、角色经验获取的基础倍率均为1，提高/降低按同类倍率加算。基础每秒回魔为“1＋0.04×精神”，再乘魔力回复速度，脱战再乘3。角色经验获取不影响副职业经验。技能冷却先按倍率计算，最后再扣魔法技能固定减少秒数，最低0。

无元素伤害受目标最高正元素抗性减伤，不享受负抗性增伤；元素伤害仍按对应元素抗性。芮兹先把目标四抗视为相反数，再计算本次命中；目标原抗性不被永久修改。
