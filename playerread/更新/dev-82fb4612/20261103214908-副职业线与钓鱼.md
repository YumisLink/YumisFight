# 副职业线与钓鱼

2026年11月3日 21时49分

- 新增草药、渔夫、厨师、药师、铭文、矿工、制皮、锻造、机械九条生活副职业，各自独立升级。
- 钓鱼加入普通、稀有、神器、传说、史诗、神话六档鱼，共 41 种，不同维度与地形出不同的鱼。
- 新增五把鱼竿：好运钓鱼竿、精致的石墨鱼竿、海潮嗜鱼竿、冥河幽光鱼竿、远行者鱼友竿。
  - 石墨竿起可在岩浆垂钓；海潮竿起一次钓更多；远行者竿还能在虚空垂钓。
  - 高档鱼竿有概率钓到钻石、黑曜石、烈焰棒，最高档小概率出下界之星。
  - 持高档鱼竿时水下呼吸更好、游得更快，还能在水面上行走。
