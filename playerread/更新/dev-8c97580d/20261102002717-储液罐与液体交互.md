# 工业体系扩展

2026年11月02日 00时27分

本次补齐从手挖矿物、区块采矿，到精炼、工艺液、合金、自动供液与电网蓄能的工业路线。通过制造新材料和设备推进生产，不另设研究点；现有发电、通货生产、农业收获和物品传送路线继续使用。

## 矿物、探矿与区块采矿

- 新增钒矿、辉钼矿、铌钽矿、锆石矿、铱矿、秘银矿、精金矿、山铜矿八种自然矿物，在主世界新生成地形中寻找和开采。钛增加主世界矿脉，同时保留末地外岛来源，已生成地形不补矿。
- 矿物生成器合并为区块采矿机。每个区块内的各矿种独立判定，既可多矿共存，也可为空矿区；首次探矿完成或放置矿机后固定结果，重新扫描、拆放或升级不会重抽。深层矿藏储量无限，不消耗地形矿块；圆石移出采矿产物。
- 共设19种深层矿藏，探矿器和矿机都须达到对应等级才能发现、选择。

| 最低等级 | 矿藏及独立出现概率 |
|---|---|
| 1级 | 铜35%、煤30%、铁15%、铅12%、山铜12% |
| 2级 | 金8%、红石12%、青金石10%、钻石4%、钒10%、魔力矿10% |
| 3级 | 钛6%、辉钼矿8%、锆石矿8%、秘银5% |
| 4级 | 铌钽矿3%、精金2%、铀2% |
| 5级 | 铱1% |

- 每种已存在的矿藏独立确定丰度：普通占50%，速度100%；贫瘠占40%，速度35%；富有占10%，速度135%。
- 新增五级探矿器与区块地图，扫描范围依次为1×1、3×3、5×5、7×7、9×9区块。扫描耗时2秒，完成后冷却5秒，期间可以移动；记录和冷却跟随玩家保存，地图支持区块详情、矿物筛选和历史翻页，探查远处不会加载地形。
- 同区块可并行建设多台矿机，各自选矿；默认生产到本机9格产物缓存装不下下一批为止，腾出空间后继续。切换矿物在当前批次完成后生效。
- 五级矿机基础速度为100%至500%，功率倍率为1、4、9、16、25。可选水提速至原来的1.5倍，或冷却液提速至2.5倍，二者互斥；按实际工作时间扣液，基础流量分别为每秒100、40mB，再乘矿机等级。
- 金属、煤与钻石每批1份，红石和青金石每批4份；魔力矿每批产2至8颗水晶，80%为3阶、20%为4阶，开工后锁定结果。

## 加工设备与精炼路线

- 新增精炼机与反应釜，均接入魔能电网工作。精炼机有4格固体输入、9格产物、一路入液和一路出液；反应釜有4格固体输入、9格产物、两路入液和一路出液，每路液体缓存20000mB。
- 补齐单金属的基础直炼、破碎熔炼和溶剂精炼路线：粗矿直接熔炼得1锭，破碎后熔炼得2锭，进一步溶剂浸出可得3份精矿。钛增加矿石、粗矿直接熔炼，便于取得首批钛锭。
- 铌钽作为复合矿处理：水洗分出铌精矿与钽精矿，万溶剂分离获得更多联产物；新增高纯铌、高纯钽、高纯铱和高纯秘银工艺。
- 加工支持双固体联产、双入液与回收产液。全部产物必须同时有空间，堵塞时暂停，避免丢弃副产物；缺料、缺电或冷却断供时保留有效进度。
- 精炼机、反应釜先选择工艺；锻炉可自动匹配或锁定配方。切换工艺排到下一批，已开工批次保留原费用、时长与结果。

## 工艺液、农料与溶剂循环

- 新增万溶剂、炽焰液、青磷水、微光、阿佐特、悬凝液六种工艺液，以及用于回收的浊溶剂；配套液体桶、名称与外观。
- 万溶剂由紫水晶碎片、农料和水制备，农料可选小麦、甜菜根或对应种子。基础制备、山铜活化、耐热精制三条路线，每批分别产1000、4000、8000mB，高级工艺提高基础原料利用率。
- 万溶剂浸出和清洗后形成等量浊溶剂；再生工艺以10000mB浊溶剂、1000mB水、紫水晶碎片及农料产出8000mB万溶剂。
- 补齐炽焰液与青磷水制备、万溶剂转微光、微光转阿佐特，以及冷却液和微光共同制备悬凝液的路线。微光制备消耗的万溶剂进入成品，不额外返还浊溶剂。
- 保留原硫化物与冷却液工艺；新工艺液用于精炼、高纯金属、辅助熔合和后续合金制造。

## 合金、零件与设备进阶

- 新增钒钢、钼钒钢、钛锆钼合金、山铜导魔合金、铌钛合金、秘银铌钛合金、精金钛合金、复合导体坯、恒辉合金、晶格基体、魔力超导材，形成逐步组合金属、工艺液与高纯材料的生产链；另加入锆质陶瓷。
- 钒钢增加炽焰液辅助工艺，减少铁用量并缩短加工周期，同时提高魔能消耗。
- 补齐基础、强化、耐热、精密四种机架，以及导魔组件、秘银导魔组件、控制组件、超导控制组件的手工与自动制造。自动制造普通导魔组件不再把1阶水晶作为消耗物料。
- 完善2至5级矿机、五级探矿器、抽水机、精炼机、反应釜、供液水晶、储液罐和蓄能器的制造与升级材料，使用阶段金属、合金和通用零件限制进阶。
- 矿机、供液水晶、储液罐和蓄能器可原地升级，消耗与工作台配方一致的差额材料，保留库存、液体、绑定、进行中批次与储能；工作台升级拒绝携带内容数据的设备。

## 抽水、供液与玻璃储罐

- 新增抽水机：接网后每秒消耗100魔能，抽取1000mB水，要求相邻六面存在水源，不移除水源。
- 权杖增加液体模式，依次选择源出口、目标入口和供液水晶完成绑定；支持重绑与清除绑定。
- 新增三阶供液水晶：两端距离限制分别为24格、128格、同维度不限距离；每20、10、1tick最多输送1000、4000、16000mB，每桶费用20、40、80魔能，仅成功转移的液量收费。缺液、满罐、类型不符或端点未加载时暂停。
- 新增基础、合金、魔导三档储液罐，容量分别为64000、256000、1024000mB。一罐一种液体，无需接网即可储液，各面均可存取。
- 储罐改为透明玻璃内胆，保留分阶机身、金色框架与符文装饰；内部显示实际液体贴图、颜色与随储量变化的液面，注入、取出和清空时同步外观。

## 电网魔力蓄能

- 新增简易、基础、复合、超导四档魔力蓄能器，接网后分别增加10万、100万、1亿、10亿魔能容量。
- 发电先供生产，余量储存，不足时使用网络存量，没有额外充放速率限制；空设备不自带电量，也不直接用水晶充能。
- 网络合并、拆分与改绑时，存量跟随实际节点；断网或卸载保留节点余额，拆除清空该节点存量，原地升级保留余额。

## 界面、自动物流与修复

- 删除排液按钮，改为按住Ctrl双击对应液体量表，提示为“按住ctrl 双击排出所有液体。”；只清空该罐，不返还材料，普通点击和单次Ctrl点击不排液。
- 储液罐及液体加工设备的量表统一加高至70像素，重排进度、状态和费用文字；矿机、抽水机显示各自有效的液体罐。
- 更新设备模型、物品图标、液体桶、名称、配方说明与JEI分类，展示联产、双入液和回收液；没有JEI也可使用设备内的工艺选择页面。
- 锁定工艺后，自动物流按材料顺序分别补入对应输入格，拒收无关材料，避免一种材料占满其他材料的格子；手动投料仍可自由摆放。
- 修复原版漏斗绕过存取方向、从底部取走原料的问题；底部只取产物。
- 修复冷却液整数扣量后，剩余已付冷却时间因罐空而无法继续使用的问题；修正矿机升级材料旁路，统一原地与工作台成本。
- 更新工业存档格式，旧格式工业数据不读取、不迁移；客户端与服务端需要同步更新。
