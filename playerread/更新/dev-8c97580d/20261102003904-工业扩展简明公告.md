# 工业扩展更新公告

2026年11月02日 00时39分

- 新增8种自然矿物，并加入主世界钛矿脉。
- 矿物生成器改为区块采矿机，支持19种固定、无限的区块矿藏。
- 新增五级探矿器与区块地图，支持范围扫描和矿物筛选。
- 矿机支持选矿、同区块并行开采和满仓自动停产。
- 调整矿机等级速度与耗能，支持水和冷却液提速。
- 新增精炼机、反应釜，支持矿物分离、高纯精炼和液体加工。
- 补齐直接熔炼、破碎增产、溶剂精炼与铌钽联产路线。
- 新增万溶剂、炽焰液、青磷水、微光、阿佐特、悬凝液。
- 新增农料制备万溶剂、高级量产和浊溶剂回收工艺。
- 新增11种合金及高级材料，生产链延伸至魔力超导材。
- 新增机架、导魔组件和控制组件，完善设备制造与升级配方。
- 新增抽水机，自动抽取相邻水源供产线使用。
- 新增三阶供液水晶与权杖液体模式，实现自动供液。
- 新增三档玻璃储液罐，可直接观察实际液体和液面高度。
- 新增四档魔力蓄能器，接网即可扩大电网储能容量。
- 矿机、供液水晶、储液罐和蓄能器支持保留存量原地升级。
- 删除排液按钮，改为按住Ctrl双击液体量表排空。
- 加高液体量表，调整界面文字位置，补齐模型、图标和JEI配方展示。
- 优化自动投料与漏斗存取，避免错料和输入原料被抽走。
- 修复冷却余量导致生产卡住的问题，统一矿机升级成本。
- 更新工业存档格式，旧工业数据不迁移，客户端与服务端需同步更新。
