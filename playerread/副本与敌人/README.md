# 副本与敌人

副本页开放10级哥布林营地、15级龙人之塔、20级城主宫殿和25级GBL教会。其他入口为未来内容。

## 城主宫殿

20级开放，沿“前庭→斧兵厅→傀儡厅→浮游回廊→王宫长廊→指挥厅→城主大厅”七房推进。前六房各八只敌人，清场后开启下一道门；第六房同时出现大将伊埃和骑士队长阿克雷两位精英，最后一房挑战光之城主赛格哈特。已经开启的门保持通行。

|敌人|需要留意的动作|
|---|---|
|驱逐者|直剑斜向上持握，举起下劈，也会沿预警方向突刺。|
|斧之驱逐者|战斧近身斧击与蓄力重劈，避开前方扇区和长条区域。|
|石巨人操控师|近身夹击与脚下石柱，石柱落点在起手时确定。|
|浮游石巨人|近身石拳和起跳压砸，留意地面预警；与操控师独立战斗。|
|大将伊埃|四向飞镖与抛掷炸弹；同轮飞镖不会重复命中同一人，炸弹在落地或碰墙处爆炸。|
|骑士队长阿克雷|体型更高大的暗红铠甲精英，持直剑下劈和突刺。|

赛格哈特轮换光剑、双段光束、扩散光环和升空落雷。光束有两次接触，光环沿地面向外扩散；升空时起落各0.5秒，高空持续3秒，释放六道预警落雷，15秒冷却。高空阶段可继续用远程攻击，近战留意躲雷并等待落地。

本图飞镖、炸弹和光招均为即时伤害，不附加中毒或感电。光招按光属性、炸弹按火属性结算。等级、同步、队伍和精英力量沿用本页[公共规则](#场次与公共规则)；经验、金币、标准装备、通货与Boss特殊池沿用[经济与奖励](../经济与奖励/README.md)，区域材料为萤石和圣痕丝绸。

## GBL教会

沿“外围广场→残破柱廊→女神内殿→诅咒祭坛”四区推进，前三个区域各有两场战斗，最后挑战堕落的阿索尔，共七场。每区清场后开启前方铁门，进入下一区才开始下一场；已经开启的门保持畅通，死亡回入口后可以沿原路返回。

|敌人|需要留意的动作|
|---|---|
|GBL教信徒|短暂起手后的近身刺击，避开前方扇形区域。|
|GBL教女信徒|保持距离投掷飞刀，刀刃沿起手确定的方向飞行。|
|龙头炮|固定炮台，交替直射和抛射；抛射先标出落点，发射后有装填间隔。|
|夜叉|近身连续爪击，也会向前扑击；留意落地点。|
|堕落的祭司|三连飞刺、近身跳跃砸地和防御气场。气场使附近6格内同伴的双防提高50%，持续4秒；与精英坚韧增幅相加，多个祭司气场不重复叠加。击杀或眩晕施法祭司可以解除其气场。|

关底阿索尔轮换使用六发飞刺、向外扩散的地面冲击波和五道女神枪矛。飞刺沿固定路线飞行；冲击波从落地点逐渐扩大，已扫过的内圈恢复安全；枪矛提前标出一排落点并依次落下。警示区域显示本次施放的位置，飞行物会被墙体和立柱阻挡。

敌人使用当前等级、难度、精英力量和组队成长规则，个人同步设置沿用本页公共说明。掉落沿用[经济与奖励](../经济与奖励/README.md)的普通副本结算，可获得天帷巨兽的鳞片、天帷巨兽的眼泪及正常装备、金币、经验和通货奖励。

## 场次与公共规则

敌人技能的近身光效、黄金飞剑及其爆炸适用[第一人称近身特效淡化](../界面与平台适配/README.md#第一人称近身特效淡化)，不改变攻击轨迹、伤害或预警时间；第三人称保留原表现。

公开场次按地图和难度匹配，不同难度使用独立场地。每名玩家单独选择同步，同场可使用不同设置；副本记住本人上次选择，与野外开关分开。本次入场后固定，退出重进可改。难度、队伍人数和本人同步选择影响看到的敌人属性。

敌人结算有独立5%概率出现通货奖励，掉宝属性影响通货品质权重，不改变这次出现概率。

## 敌人生命成长

所有敌人从各自1级基础生命开始，每升一级乘1.08，统一公式为“1级基础生命×1.08的（等级−1）次方”，没有20级分段。普通怪1级基础50，副本Boss和末影龙为2,000，凋灵为1,500；训练沙袋仍使用固定基准。

按单人、普通难度、标准物种计算，普通怪60级约4,688生命、80级约21,850生命；副本Boss同等级分别约187,513和873,990生命。精英继续在普通怪基础上乘3，强壮力量再提高50%；野外物种差异、队伍人数及难度仍各自生效。

王者难度生命×4、攻击×2.1；地狱生命×6、攻击×3。防御、抗性与攻击的等级成长沿用现有规则；同步开关决定本人的有效敌人等级，见上文场次说明。

## 训练沙袋

使用3块任意羊毛、1块干草块和1块橡木台阶，在工作台按“上中羊毛、中排羊毛／干草块／羊毛、下中橡木台阶”合成训练沙袋；创造物品栏也可取得。在有完整支撑、留出两格高度的位置右键放置。

沙袋不会攻击、不会被击退或拉走，双防和元素抗性为0，按攻击者等级计算等级差。可反复用普攻和技能攻击，显示实际伤害数字，单次伤害超过耐久基准仍完整显示；不会死亡，也不产生经验、金币、材料、通货或击杀效果。

普通右键放置的沙袋在本人客户端立即显示受击和伤害数字，命中与技能效果由服务器确认。普攻、投射物、召唤物和持续伤害沿用各自技能规则，适用的怒气、血剑层数、吸血、技能回血和负面状态正常触发，技能费用、冷却及脱战计时照常生效。双刀、多目标或重发不会额外产生怒气；具体产耗见[恶魔猎手怒气](../角色与转职/README.md#恶魔猎手怒气)。

动作结束后汇总已确认伤害；飞行物、流血等后续伤害结束后补充汇总，按无属性、光、火、冰、暗分别着色，消息只给本人。服务器拒绝的命中不计入汇总，也不触发实际效果。沙袋仍不会死亡、移动或产生击杀奖励。

空手右键查看说明，Shift＋空手右键收回自己放置的沙袋。沙袋随世界保存，创造模式可以移除任意沙袋。

### 计时伤害测试

在副本外手持训练沙袋，Shift＋右键地面开始20秒测试，Shift＋Alt＋右键开始60秒测试；左右Alt均可，不再弹出选择界面。沙袋物品不消耗；每人同一时间只能进行一轮。首次有效命中开始计时，只有放置者及其召唤物的伤害计入。普攻、技能、投射物和持续伤害按正常规则结算，服务器确认的命中会触发适用的实战效果；沙袋仍不死亡，也没有击杀奖励。

左上角伤害榜显示累计伤害、DPS及剩余时间。DPS使用总伤害除以首次命中后经过的时间，停手也继续计时；结束后分别除以20秒或60秒。只计时段内发生的有效命中，迟到确认的有效命中可在结果保留期间补记。结果保留1分钟，开始新测试或进入副本时清除。

Shift＋空手右键计时沙袋可提前取消，死亡、断线或换维度也会取消未完成的测试，取消不保留结果。测试结束或取消时沙袋消失，不掉落物品；已生效的正常战斗效果不会回滚。

## 精英力量

新生成的精英在保留原生命×3、攻击×1.5的基础上，等概率得到一种力量：强壮使最大生命提高50%；狂暴使伤害提高30%；坚韧使物理和魔法防御提高50%；元素守护使四种元素抗性各+30。目标提示显示力量类型，已经存活的旧精英不补抽。

英雄王继承后，强壮、狂暴、坚韧按对应属性或伤害的“提高”结算，元素守护提供四抗固定加值。英雄装备BUFF的时长、刷新与清除见[战斗](../战斗/README.md)。
