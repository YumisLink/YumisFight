# 副本与敌人

副本页开放10级哥布林营地、15级龙人之塔。其他入口为未来内容。

同一副本共享当前公开场次，加入已有场次沿用其难度与同步设置。难度、队伍人数和等级同步会影响敌人的实际属性。

敌人结算有独立5%概率出现通货奖励，掉宝属性影响通货品质权重，不改变这次出现概率。

## 训练沙袋

使用3块任意羊毛、1块干草块和1块橡木台阶，在工作台按“上中羊毛、中排羊毛／干草块／羊毛、下中橡木台阶”合成训练沙袋；创造物品栏也可取得。在有完整支撑、留出两格高度的位置右键放置。

沙袋不会攻击、不会被击退或拉走，双防和元素抗性为0，按攻击者等级计算等级差。可反复用普攻和技能攻击，显示实际伤害数字，单次伤害超过耐久基准仍完整显示；不会死亡，也不产生经验、金币、材料、通货或击杀效果。

空手右键查看说明，Shift＋空手右键收回自己放置的沙袋。沙袋随世界保存，创造模式可以移除任意沙袋。

## 精英力量

新生成的精英在保留原生命×3、攻击×1.5的基础上，等概率得到一种力量：强壮使最大生命提高50%；狂暴使伤害提高30%；坚韧使物理和魔法防御提高50%；元素守护使四种元素抗性各+30。目标提示显示力量类型，已经存活的旧精英不补抽。

英雄王继承后，强壮、狂暴、坚韧按对应属性或伤害的“提高”结算，元素守护提供四抗固定加值。英雄装备BUFF的时长、刷新与清除见[战斗](../战斗/README.md)。
