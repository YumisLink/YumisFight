# 角色与转职

角色最高80级。升级获得属性点和SP；属性加点按住Shift可最多投入5点。

新角色按I打开模组菜单，进入职业技能页后可选择鬼剑士、魔法师或恶魔猎手，首次确认分别领取1级太刀、学徒法杖或普通战刃。职业卡片随页面宽度自动换行，窄屏可滚动查看。本次启用新的角色成长记录，第一套从1级开始；旧单职业成长不读取。三种基础职业的职业防护均为35%。

独立转职页已删除。达到20级并取得现有通用转职资格后，在职业技能页底部选择分支。鬼剑士可选剑魂、鬼泣、阿修罗、狂战士或神谕代行者；魔法师可选召唤师或[日月魔法师](../技能/日月魔法师.md)；恶魔猎手可选浩劫。通用资格可通过已有的一次性转职解锁券取得，管理员也可授予；不使用旧杀敌、交材料任务。

## 恶魔猎手怒气

恶魔猎手与浩劫使用怒气。战斗HUD和角色属性页显示当前怒气／上限，隐藏魔力与魔力恢复显示；右侧保留献祭光环、恶魔变形等状态计时。怒气上限100，战刃普攻每个有效周期产生10点，双刀与多目标不重复计算；利刃投掷命中产生20点，献祭光环每次脉冲命中产生5点。技能按各自说明消耗怒气，脱战后每秒减少10点。攻击[训练沙袋](../副本与敌人/README.md#训练沙袋)也按相同命中规则产怒。

## 职业配置

在角色属性左栏直接查看职业配置；左键切换，右键或点击“改”重命名，名称最多16个字符。列表可单独滚动；窄屏在角色正文中显示。每人初始有8个容量，第一套免费建立；其余配置须消耗职业重置券创建。职业拓展券留待后续，本期没有投放。

当前使用的配置至少20级且已转职后，主手右键职业重置券并确认，会先消耗一张券，保留旧配置并进入新的20级配置。新配置0经验、38点自由属性、310 SP，尚未选择基础职业和技能，不重复赠送武器。之后在职业技能页依次选择基础职业与转职，操作与第一套相同。未选完时也能切回旧配置。

各套分别保存战斗等级与经验、职业、属性加点、SP、技能学习、三层共24格技能排列，以及个人等级同步和默认副本同步开关。背包、当前穿戴、通货、副职业和商城契约共用；转职解锁与觉醒资格全角色共享，但每套仍须达到对应等级并自行学习技能。实际键盘按键继续用本机统一设置。

允许多套处于相同基础职业阶段，最终转职每种只能拥有一套；技能页会禁用已拥有的转职。当前不提供配置删除，选定的基础职业和转职不能重选。转职重置券已移除；职业重置券改用于创建配置，不再清空当前职业。自由属性和技能仍可各自免费重置。

切换配置、创建配置和使用升级券都要求存活，在副本与训练外达到[脱战条件](../战斗/README.md)，结束施法、动作和全部技能冷却；取消或条件不符不消耗券。切换不回复生命、MP和护盾，只将超过新上限的部分裁到新上限。原职业资源、持续技能和召唤物结束，敌方负面状态保留。

穿戴不自动更换。不符合新配置等级或职业资格的装备仍留在原位，但暂时不提供属性、词条及套装效果。光剑需要剑魂，或已学习指令之意的神谕代行者；职业减伤仍生效，左侧不再显示该行文字。

职业重置券价格和购买方式见[商城](../经济与奖励/README.md#点券与重置券)。

## 升级券

目前制作了1级升级券、10级升级券和满级升级券，均为实体道具，暂未加入商城或自然掉落，可由管理员发放。主手右键后确认，只升级当前配置，使用条件见[职业配置](#职业配置)。

升级后本级经验清零，按实际增加的等级获得属性点和SP，已有技能学习和属性投入保留。例如当前上限80级，75级使用10级券会升至80级并消耗整张；已满级时不会消耗。满级券按使用时的等级上限生效，未来正式开放90级后，已有满级券也会直升90级。本期等级上限仍为80。

50级可使用已有的一次性觉醒券获得觉醒资格，无职业前置；管理员也可按现有条件授予。学习具体一觉仍需对应转职并自行花SP。技能页显示觉醒称号，没有玩家觉醒按钮。资格全角色共享，新配置不会自动学习觉醒技能。

职业配置与成长保存在当前服务器，重连与服务器重启后恢复；本次第一套从1级重新开始，不合并旧角色记录，见[首页](../README.md)。
