# 角色与转职

角色最高80级。升级获得属性点和SP；属性加点按住Shift可最多投入5点。

新角色首次打开职业技能页时选择鬼剑士或魔法师，首次确认分别领取1级太刀或学徒法杖。已有角色保留原职业；使用重置券重新选择不会重复领取武器。鬼剑士与魔法师的基础职业防护均为35%。

独立转职页已删除。达到20级并取得现有通用转职资格后，在职业技能页底部选择分支。鬼剑士可选剑魂、鬼泣、阿修罗、狂战士或神谕代行者；魔法师可选召唤师或[日月魔法师](../技能/日月魔法师.md)。通用资格可通过已有的一次性转职解锁券取得，管理员也可授予；不使用旧杀敌、交材料任务。

| 转职 | 主要攻击属性 | 职业防护：怪物直接伤害减免 | 一觉称号 |
|---|---|---:|---|
| 召唤师 | 魔攻、智力 | 35% | 月之女皇 |
| 日月魔法师 | 魔攻、智力 | 35% | 日月魔法师 |
| 剑魂 | 物攻、力量 | 65% | 剑圣 |
| 鬼泣 | 魔攻、智力 | 50% | 弑魂 |
| 阿修罗 | 魔攻、智力 | 25% | 大暗黑天 |
| 狂战士 | 物攻、力量 | 75% | 狱血魔神 |
| 神谕代行者 | 物攻、力量 | 65% | 神谕代行者 |

职业防护不代替防御、抗性、护盾及闪避；环境伤害沿用[战斗规则](../战斗/README.md)。鬼泣学习凯贾后，怪物直接伤害在职业防护后再乘0.9。

## 职业重置券与转职重置券

两种券的点券价格与购买方式见[商城](../经济与奖励/README.md#点券与重置券)。实体券可交易，主手右键后确认使用。必须在副本外达到[脱战条件](../战斗/README.md)，并且所有技能冷却结束；没有可重置状态、取消或失败不消耗券。

- 职业重置券：退回未选择基础职业，返还全部已学技能SP，重新选择鬼剑士或魔法师。
- 转职重置券：退回原基础职业，保留基础技能和绑定，返还转职技能SP并清除相应绑定；未转职时不能使用。

两种券都保留现有通用转职资格和觉醒标记，清除召唤物和相关职业临时效果。等级、属性加点和装备保留，生命与MP不回复，敌人施加的负面状态照常保留。自由属性与技能加点仍使用各自的免费重置。

人物侧栏自由点下显示当前职业减伤；技能页在窄屏时将其放到顶部摘要。光剑需要剑魂资格，或神谕代行者已学指令之意；重置后不满足资格的光剑保留在物品栏，不能作为有效职业武器。

50级可使用已有的一次性觉醒券获得觉醒资格，无职业前置；管理员也可按现有条件授予。学习具体一觉仍需对应转职并自行花SP。技能页显示觉醒称号，没有玩家觉醒按钮。已有当前格式角色保留职业及已学觉醒资格。

当前存档代际保存已选职业、任务完成标记与觉醒资格。旧版本角色不合并进当前记录，见[首页](../README.md)。
