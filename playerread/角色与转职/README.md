# 角色与转职

角色最高80级。升级获得属性点和SP；属性加点按住Shift可最多投入5点。

鬼剑士20级接取共用转职任务：击杀50只有效等级不低于20的敌人，其中包括3只精英，提交32铁锭和16青金石。任务完成后，在剑魂、鬼泣、阿修罗和狂战士中选择一个。四个分支共用任务进度，每次击杀只计一次。

| 转职 | 主要攻击属性 | 职业防护：怪物直接伤害减免 | 一觉称号 |
|---|---|---:|---|
| 剑魂 | 物攻、力量 | 65% | 剑圣 |
| 鬼泣 | 魔攻、智力 | 50% | 弑魂 |
| 阿修罗 | 魔攻、智力 | 25% | 大暗黑天 |
| 狂战士 | 物攻、力量 | 75% | 狱血魔神 |

职业防护不代替防御、抗性、护盾及闪避；环境伤害沿用[战斗规则](../战斗/README.md)。鬼泣学习凯贾后，怪物直接伤害在职业防护后再乘0.9。

## 免费重转

副本外、达到[脱战条件](../战斗/README.md)，而且所有技能冷却结束后，可以在职业页免费重转。返还旧职业技能实际消耗的SP，删除这些技能的快捷栏绑定；基础三技能及绑定保留。旧职业阵法、附身、刻印、蓄血等临时效果清除，当前生命和MP不回复，敌人施加的负面状态照常保留。自由属性继续使用独立的免费重置。

转职页已移除职业技能预览入口。人物侧栏自由点下显示当前职业减伤；技能页在窄屏时将其放到顶部摘要。光剑仍需剑魂资格；重转后不满足资格的光剑保留在物品栏，不能作为有效职业武器。

50级可直接花SP学习一觉，不需要额外觉醒任务。学会后职业页显示对应觉醒称号。

当前存档代际会保留已选职业和任务进度。旧版本角色不合并进当前记录，见[首页](../README.md)。
