# 经济与奖励

金币、职业币和加工通货是不同资源。击杀金币倍率不改变出售价格；战斗经验倍率不改变副职业经验或管理员奖励。

## 点券与重置券

点券是独立账户余额，初始0，不占背包、不能交易；当前仅由管理员发放或扣除，没有掉落、金币兑换或充值入口。商城顶部显示点券余额，“道具”分类以100点券出售职业重置券、50点券出售转职重置券。

购买获得可交易实体券，主手右键后确认使用。扣款与发券一起完成；余额不足或背包放不下时不扣款，重复请求不重复发券。两种券的使用条件与重置结果只在[角色与转职](../角色与转职/README.md#职业重置券与转职重置券)维护。

已有16种通货，其稀有度与品质边框会显示在物品提示中。自然池不直接产出史诗/神话升级石、套装石、词条宝石和仅创造获取的词条拆解石。

装备分解统一在下文出售页面操作。工业也可生产通货，实际配方、能耗和时间以设备界面为准。

相关：[词条](../词条/README.md)、[工业](../工业/README.md)、[副职业](../副职业/README.md)。

本次将金币、通货和掉落领取统一归入独立处理；当前奖励、出售价格和消费规则保持。

## 商城与霸王之契约

商城首件商品为霸王之契约，100000金币购买7×24小时，立即生效。重复购买从当前到期时间和现在两者较晚处续7天，穿戴额度始终只增加5级。离线继续计时，到期时间按香港时区显示。

契约只放宽装备等级要求，不解锁职业和装备槽。到期装备留在原槽，等级不再满足时属性与授予技能失效，恢复资格后重新生效。

## 出售装备

按I切换同级“出售”Tab，或在普通背包/次元背包点击“出售装备”直接定位相应来源。界面按九列真实槽位显示，切换来源保留已选装备；可全部可售、清空，右侧查看装备详情，底部固定显示总件数和报价合计。小窗口使用紧凑详情或悬浮提示。点击“确认出售”后再次确认；镶嵌宝石随装备一起出售。当前主手、穿戴装备及溢出待领取物品受保护。选中装备或报价期间发生变化时整笔拒绝并刷新，不会只卖掉其中一部分；重复请求不重复收款。

狄瑞吉之血进入稀有通货自然池；词条拆解石仍仅创造获取。史诗与神话装备获取、自然装备品质及腐化规则见[装备](../装备/README.md)。

## 分解与无色小晶块

在I菜单“出售”页面切换“分解”，选择普通背包或次元背包装备，确认后再次点击才执行。当前主手、穿戴装备和待领取物品受保护；要分解主手请先移到其他背包格子。镶嵌宝石会一并销毁，不额外返还。装备制作器不再提供分解入口。

| 装备品质 | 每件分解产物 |
|---|---|
| 普通 | 1～3个无色小晶块 |
| 稀有 | 1～3枚蜕变石 |
| 神器 | 增幅石、狄瑞吉之血、打孔石中随机一种，1～3枚 |
| 传说 | 富豪石、混沌石、升级石中随机一种，1～3枚 |
| 史诗 | 1枚史诗装备升级石 |
| 神话 | 1枚神话装备升级石 |

普通至传说的1、2、3个等概率，同件产物为同一种，候选种类等概率，不受掉宝率影响。产物会公开掉到脚边，其他玩家也能拾取，沿用普通掉落的5分钟寿命。

无色小晶块在拾取后直接存入拾取者的余额，不占背包，背包满也能领取；余额在I菜单商城查看，退出或重启后保留。本次尚无消费用途。
