# 经济与奖励

金币、职业币和加工通货是不同资源。击杀金币倍率不改变出售价格；战斗经验倍率不改变副职业经验或管理员奖励。

已有16种通货，其稀有度与品质边框会显示在物品提示中。自然池不直接产出史诗/神话升级石、套装石、词条宝石和仅创造获取的词条拆解石。

传说、史诗和神话装备整件分解各给1枚对应升级石。工业也可生产通货，实际配方、能耗和时间以设备界面为准。

相关：[词条](../词条/README.md)、[工业](../工业/README.md)、[副职业](../副职业/README.md)。

本次将金币、通货和掉落领取统一归入独立处理；当前奖励、出售价格和消费规则保持。

## 商城与霸王之契约

商城首件商品为霸王之契约，100000金币购买7×24小时，立即生效。重复购买从当前到期时间和现在两者较晚处续7天，穿戴额度始终只增加5级。离线继续计时，到期时间按香港时区显示。

契约只放宽装备等级要求，不解锁职业和装备槽。到期装备留在原槽，等级不再满足时属性与授予技能失效，恢复资格后重新生效。

## 独立出售

在普通背包或次元背包使用“出售装备”进入独立多选面板，可切换来源、全选、清空，查看报价合计后确认。当前主手、穿戴装备及溢出待领取物品受保护。选中装备或报价期间发生变化时整笔拒绝并刷新，不会只卖掉其中一部分；重复请求不重复收款。

狄瑞吉之血进入稀有通货自然池；本批13件具名装备与词条拆解石仍仅创造获取。腐化和宝石获取见[装备](../装备/README.md)与[词条](../词条/README.md)。
