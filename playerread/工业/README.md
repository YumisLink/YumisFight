# 工业

工业魔能独立于角色MP。设备只在所需区块加载时运行，可建立采集、加工、供能、传送和自动收获产线。

使用魔力草和魔力矿取得前期水晶，制作加工机、锻炉和信标。已有燃煤、日曜、涡轮、风能、温差、核能和RTG能源。水与冷却液接入标准流体能力。

权杖Shift右键空气切换供能、连网和传送模式。先选择核心再选择设备；连网选择两个核心；传送先选目标容器接收面再选水晶。

设备右键打开界面，问号查看实际工作规则。配方重载只影响新批次，已开工的费用、时间和结果保持。拆机掉落空机器、库存和托管原料，流体与余能清空。

魔能熔炉与原版普通熔炉使用同一组熔炼配方、产物和基础时长，也接受数据包增加的普通熔炼配方；高炉、烟熏炉专属配方除外。每份消耗100点魔能，五阶速度依次为4、16、32、64、128倍，三个输入槽轮流加工。粉碎矿料也能用原版普通熔炉熔炼。JEI中可在普通熔炼分类查看。

成熟工业可以生产材料和通货。已有煤、硫化物和温差发电组合允许净增能。未投放的高阶水晶和设备仍未开放。
