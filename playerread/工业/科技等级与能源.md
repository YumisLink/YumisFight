# 科技等级与能源

工业材料、工艺液和科技建筑采用T1～T6分级。物品说明中的材料等级、建筑科技等级和工艺能力分别显示；固定型号的专用机器可以处理高于自身科技等级的工艺。配方中的魔能数值是每批总量。

## 科技阶段与颜色

| 阶段 | 名称与主色 | 代表材料 |
|---|---|---|
| T1 | 普通，铜色 | 铁、铜、煤、铅、山铜、水 |
| T2 | 稀有，青色 | 金、红石、青金石、钻石、紫水晶、钒、钒钢 |
| T3 | 神器，钛银色 | 钛、钼、锆、秘银、钛锆钼合金、冷却液 |
| T4 | 传说，暗蓝色 | 铌钽、精金、铀、泰拉石、精金钛合金 |
| T5 | 史诗，紫色 | 铱、时空石、恒辉合金、魔力超导材 |
| T6 | 神话，金色 | 恒星合金、约束晶格、聚变燃料、恒星点火芯 |

科技核心决定同阶段建筑的金属和饰边颜色。功能水晶、火焰和液体保留各自的颜色。水晶的1～10阶表示可存魔能，并不等同于建筑科技等级。

已分级的工业物品按科技等级使用与装备、通货一致的品质名称颜色和物品格外框：T1普通、T2稀有、T3神器、T4传说、T5史诗、T6神话。设备按科技等级显示，不以工艺能力上限或型号数字代替；机器本体仍使用上表的科技配色。这些品质颜色用于辨识，不会给机器或工具增加装备词条。

玩家使用钻石镐等工具手动采矿，最多取得T3原矿；更强工具和精准采集也不会掉落T4、T5天然矿石。高阶原矿由对应矿机取得。T3以上原矿、粉碎矿、精矿和金属的加工需要相应能力的工业机器，普通熔炉不能代替。

## 方块、核心和机外壳

T1直接用基础材料和低阶水晶起步，没有T1科技方块。T2起先制造科技方块，再拆成科技核心，将核心装入对应科技机外壳，最后制造或升级机器。

| 目标科技方块 | 每批材料 | 使用锻炉 |
|---|---|---|
| T2 | 铁锭4、铜锭4、山铜锭4 | 1级 |
| T3 | 钒钢4、金锭4、紫水晶碎片4 | 2级 |
| T4 | 钛锆钼合金4、秘银锭4、锆质陶瓷4 | 3级 |
| T5 | 精金锭4、泰拉石锭4、铀锭4 | 4级 |
| T6 | 恒星合金4、约束晶格4、超导控制组件4 | 5级 |

每个科技方块可合成2枚同级科技核心。T2～T6机外壳使用同级科技方块1、核心1，再加上一阶段机架2；T6沿用精密机架。T1机外壳使用基础机架1和T1核心1。

机器制造采用有形状的九宫格：常规机身以材料构成外框，功能件放上方，机外壳居中，两侧放线路。储液罐采用玻璃容器形状，抽水机采用玻璃、铜底座与活塞。高阶制造以科技机外壳和金属零件推进。

升级配方为十字形：上方机外壳、中央前级机器、左右导魔件、下方机架。原地升级时，手持目标科技机外壳右键旧机器，背包中备齐另外的零件；消耗与工作台配方一致，省去作为中央材料的旧机器物品。

| 目标科技等级 | 除前级机器外的升级材料 |
|---|---|
| T2 | T2机外壳1、导魔组件2、基础机架1 |
| T3 | T3机外壳1、导魔组件2、强化机架1 |
| T4 | T4机外壳1、导魔组件2、耐热机架1 |
| T5 | T5机外壳1、秘银导魔组件2、精密机架1 |

型号档次可能跨科技阶段，例如三阶传送水晶属于T5；以物品说明和实际配方为准。探矿器有自己的工具形状配方。

## 最低自动发电

1. 收集铁、铜、山铜、煤和低阶水晶，制作T1信标、燃煤发电机、一级矿机，以及移物水晶与权杖。
2. 找到有煤矿藏的区块；可先制作一级探矿器扫描。将矿机和发电机放在信标覆盖范围，矿机选择煤。
3. 在发电机中投入首批煤，先启动电网。用移物水晶把矿机产物接到燃煤发电机，后续煤即可自动回送；也可用漏斗从发电机背面投燃料。
4. 留出产物空间，保持所需区块加载，便可形成持续产煤、回送燃料、发电的循环。

普通丰度、无冷却、无芯片时，一级煤矿机20秒产1煤，一批耗50魔能，平均2.5魔能/秒。燃煤发电机每煤运行32秒，产能60魔能/秒；一级移物水晶每次成功搬运耗5魔能。这个起步循环无需抽水机和冷却液。日曜、风能可补充供能；升级涡轮后再加持续供水。

## 铀燃料与核能

铀锭不再直接发电。铀燃料须经过六道工序：

`粗铀 → 碎石机 → 粉碎铀矿 → 精炼机浸出 → 铀精矿 → 反应釜转化 → 铀转化料 → 离心分离机 → 富集铀料 → 成型装配机 → 核燃料芯块 → 成型装配机装入锆质包壳 → 铀燃料棒`

1粗铀可以得到2份粉碎矿，再制成2份精矿、2份转化料、1份富集铀料及1份贫化铀料。富集料制成4枚芯块，配合另外制作的锆质包壳，可装配2根燃料棒。

核反应堆制造需要T5机外壳、高纯铱、超导控制组件与核能核心。一根铀燃料棒发电800秒，产能108000魔能/秒，总计8640万魔能，运行时持续耗水100B/秒，燃烧结束产出乏燃料棒。缺水、输出满仓时暂停；乏燃料可送入后续处理线。

## 同位素密封热源

三类热源各有独立的多步游戏工艺：

- Pu-238：专用前驱组件 → 活化辐照 → 冷却 → 分离 → 锆质包壳密封。
- Cm-244：乏燃料棒 → 冷却 → 反应釜后处理 → 分离含锔料 → 锆质包壳密封。
- Th-228：专用前驱组件 → 活化辐照 → 冷却 → 分离 → 锆质包壳密封。

RTG只接受密封热源，不消耗水或冷却液。三种热源均可在加载运行中持续800000秒，约9.26天。

| 密封热源 | 魔能/秒 | 总魔能 |
|---|---:|---:|
| Pu-238 | 108 | 8640万 |
| Cm-244 | 540 | 4.32亿 |
| Th-228 | 2160 | 17.28亿 |

## T6人造恒星

人造恒星使用T6金色科技体系。先在五级锻炉制成恒星合金、约束晶格，再制造T6方块、核心、机外壳、控制器和点火芯。专属3D模型后续制作，目前沿用临时机身外观。

结构为5×5×5空心外壳：控制器位于底层正面中央，另外放97块T6科技机外壳，内部3×3×3留空。界面的“结构”页可逐层查看。

燃料由两条线路汇合：水 → 重水 → 氘燃料胶囊；水 → 盐水 → 锂盐 → 氚燃料胶囊；成型装配机将两者制成聚变燃料胶囊。全线使用固体和液体，不需要气体管网。

每次点火需恒星点火芯1枚与1亿魔能，充能只使用当前生产后的电网余量。备好燃料与冷却液后完成点火，下一刻开始发电。每枚聚变燃料持续20秒，产能5000万魔能/秒，总计10亿魔能，运行时消耗冷却液100B/秒并返还空胶囊。

缺燃料、缺冷却液或结构损坏会熄火，补齐后须再次支付点火芯和点火能量；未燃尽的燃料保留。主动停机、区块卸载和世界重启只暂停，恢复时继续原点火状态，不补算离线产能。

## 专用机器与基础能耗

精炼机、反应釜、离心分离机、同位素活化机、成型装配机和热力蒸馏设备各有单一型号、单条产线，按原料和工艺能力推进。

| 设备 | 科技等级 | 工艺能力上限 |
|---|---:|---:|
| 精炼机 | T2 | T5 |
| 反应釜 | T3 | T5 |
| 冷却液混合器 | T3 | T3 |
| 热力蒸馏设备 | T3 | T4 |
| 成型装配机 | T3 | T5 |
| 离心分离机 | T4 | T5 |
| 同位素活化机 | T5 | T5 |

冷却液混合器的制造配方将坩埚放在机壳下方；反应釜的坩埚放在机壳上方。其余材料及位置以JEI为准。

混合器支持超速芯片。基础配方5秒产1B冷却液，单批2500魔能，即500魔能/秒。每件超速芯片使速度×1.5、单批耗能×2，所以每秒需能×3；存储芯片继续逐件扩容。

基础碎石工序每批50魔能；普通熔炼每份50魔能；抽水机基础每秒10魔能、1B水；通货制造每枚600魔能。物品与液体传送每次成功操作分别按档次收5、25、100魔能；收种每株20魔能。加速、并行、液体处理与供能细节见[加工与并行产线](加工与并行产线.md)和[工业首页](README.md)。
