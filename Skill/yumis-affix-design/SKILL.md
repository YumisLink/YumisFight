# 词条设计

本 skill 随项目保存在 `Skill/`。项目根目录为本文件上两级。先读根目录 `AGENTS.md`、[词条设计档案](../../doc/词条设计档案.md)、[装备设计档案](../../doc/装备设计档案.md)和[数值设计规范](../../doc/数值设计规范.md)。实现前读模块架构和迁移记录。

先检索现有定义、操作处理器和两个档案，按以下语义签名去重：作用对象＋作用域＋触发＋运算/乘区＋阶段＋元素或技能标签＋资格限制。数值、正负、区间、显示名和装备来源不是新机制。相同签名复用效果族及处理器，来源区间可以独立；已有来源ID永久保留。把归并结论同时写入词条档案和装备档案，并维护来源反向索引。

给每个设计补全计算单位、固定/可洗、上下限关联、成长、腐化倍率、宝石增幅资格、触发去重及失效清理。区分：

- 本件固定值/百分比：先结算该件，再进入角色基础。
- 角色“提高/最终提高”：MUT；临时固定加值：ADD；“总增”：逐项独立乘算。
- 固定元素附伤：“附加X～Y点火属性伤害”。
- 结算后比例追加：“造成伤害后，额外造成相当于该次伤害X%的火属性伤害”；另列追加基数、二次防御和禁止递归规则。
- 隐藏机制参数：用效果合同中的普通数值或开关，不用统一属性包装模拟。

负数只显示一个负号。“吸血值”与换算后的“吸血率”、“魔法技能”与“魔法伤害”及“基础三技能”不可混称。展示文案不是效果解析来源。

新增定义使用稳定且不复用的ID。名称/说明/投放修改与效果revision分开；效果调整递增revision，保留随机分位及独立腐化倍率。固定值、技能等级、成对附伤、技能参数和法师之血分别按自身语义处理；未知当前快照保留并记录，不猜测、不恢复早期代际。

最后同步装备来源、词条档案、数值规范、TODO和玩家模块 Wiki。未设计或未实现项明确标识，不宣称已开放；测试和提交范围服从用户当前指令。
