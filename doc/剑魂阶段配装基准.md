# 剑魂阶段配装基准

2026年10月30日更新：阶段装备与SP输入保持，敌人当前已实施从1级起统一每级生命×1.08，详见[当前生命曲线](普通敌人生命曲线提案.md)。下文“每级×1.06生命和双防”一节仅保留当时对比，不能作为当前敌人数值。

2026年10月29日。平衡采用有装备等级落差、有限正确词条及合法SP预算的剑魂。60级基准为45级满词条传说、每件1条目标词条；80级基准为60级满词条传说、每件2条目标词条。普通敌人以日常小技能击败为目标，三段斩和地裂波动剑作为观察项，觉醒作为爆发参考。

本方案固定计算输入，尚未修改游戏掉落、装备定义、敌人属性或向存档发放装备。以60/80级这两档替代此前仅同级白武器的主平衡基准；旧白武器表保留为裸装对照。

主线防具选轻甲，仅使用当前轻甲的双防与闪避属性，没有额外职业轻甲精通加成。首饰固定选生命手镯、魔力项链、力量戒指；这些是模板自带属性，不占随机词条条数。10/20级档是阶段目标配装，品质和获取用时不视为自动保证。

装备最低等级分别为辅助装备50、魔法石60、耳环70。因此严格按全身45级定义60级档时，三个特殊槽留空；按全身60级定义80级档时，只有辅助装备和魔法石可用，耳环留空。人物已经解锁槽位不会产生45级辅助装备或60级耳环模板。

“满词条”按加工上限6条定义：传说自然生成4条，需要继续加工到6条。本轮不把自然4条传说和加工6条传说混算。史诗、神话及具名装备属于额外高配分支，不进入主平衡档；创造目录专属装备和当前仅能由该途径提炼的宝石不作为正常成长输入。

## 正确词条和取值

“正确”是本槽选定的目标，不代表其他词条无效。其他词条仍按实际效果参与MP、精神、魔攻、双防和抗性，不能统一置零。光剑剑魂的直接伤害按物理计算，魔攻与智力不提高这些直接物理伤害。

防具当前直接增加剑魂输出的随机词条是力量；轻甲没有基础力量，不能生成力量%词条，也不允许武器物攻或攻速词条。因此80级轻甲的第二条目标为生命，不把每件防具虚算成两条输出词条。辅助装备和首饰的词条资格按各自模板读取。

所有可洗词条统一取随机区间的50%分位；普通随机roll为1.0，攻击速度采用其独立等级区间中点。力量等百分比先在本件装备结算，完整物品贡献再加入角色基础。目标词条类型是固定的构筑输入，不代表随机掉落通常能有这些组合。每件的六条均为不同合法效果，计数不含基础模板。

角色每级获得的2点自由属性全部投入力量。1/10/20/40/60/80级分别投入0/18/38/78/118/158点；精神、智力没有自由加点。角色自然成长和装备其他词条照常计入。

## 获取和后续验证

普通模板可制作后用现有通货提升品质；传说自然4条，加工到6条使用既有加工路径，目标组合通过现有掉落与重洗/替换选择。六条中有多少目标词条是本轮指定的装备条件，投入时间、掉落成本及达到概率另行衡量。没有要求玩家一到等级便自动获得这套装备，也不新增免费装备发放。
