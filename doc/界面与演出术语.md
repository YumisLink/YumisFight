# 界面与演出术语

2026年11月4日，记录用户明确使用的特殊名词，后续同类技能按此理解。面向玩家的唯一术语定义见[显示与演出术语](../playerread/界面与平台适配/README.md#显示与演出术语)，开发说明引用该定义，不再另起同义名称。

## 对应实现

| 术语 | 当前复用入口 | 本次应用 |
|---|---|---|
| 读条 | SkillCastBar；ChantClient提供正向进度 | 既有咏唱 |
| 反向读条 | 同一SkillCastBar，由内容传入剩余比例 | 眼棱完整2.2秒动作从满到0，结束或中断移除 |
| 量谱 | CareerHud.timer／badge与既有右侧布局 | 献祭光环按6秒剩余时间显示图标、秒数和比例条 |
| 拖尾 | 技能内容记录实际运动点，按时间淡出 | 恶魔追击保留最近350毫秒路径，不替换成随朝向旋转的直线 |
| 连续挥动 | 内容快照给出段数与动作时长，统一采样左右手 | 恶魔追击命中后8刀，基础0.8秒并受施速影响 |
| 固定视角 | 已有Handler.camera与按施法ID恢复机制 | 刃舞固定世界观察点，不追随角色穿斩 |
| 完全隐藏 | 本帧玩家渲染取消与附身特效同一时间轴 | 身体、装备、名字、火焰、阴影及角翼同时隐藏 |

这些词描述展示与交互，不自行授予无敌、减伤、命中或重力权限。技能的资源、伤害与保护仍由各自业务规则和服务端认可动作决定。
