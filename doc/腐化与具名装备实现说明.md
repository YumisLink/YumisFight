# 腐化与具名装备实现说明

本批实现范围以[装备档案](装备设计档案.md)、[词条档案](词条设计档案.md)、[数值规范](数值设计规范.md)为准。仅支持modules-v1、装备version9，当前格式新增字段默认不腐化、倍率1、无装备BUFF、契约未激活。没有早期格式迁移或兼容转接。

## 模块合同与调用

- equipment：NamedEquipment注册13个模板；EquipmentEffects.Snapshot承载固定效果、装备来源和授予技能；EquipmentEligibility提供契约额度。EquipmentRules处理腐化/神圣/镶嵌，GemExtraction仅注册两配方；EquipmentContracts实现EquipmentEntitlements，经济模块通过合同准备同笔WAL变更。
- affixes：AffixDefinition记录可洗区间/固定值；Affix保存corruptionMultiplier，Anchor保留未乘腐化的来源分位。读取为副本，不由文本推断；效果定义版本变化保留分位和倍率。数值词条共用处理器，来源配置见词条档案。
- combat：EquipmentDamage共用分量过滤/抗性/比例追加/吸血；EquipmentBuffs保存source、stacks、expires。EquipmentHitEffects和职业命中效果共享同一Life草稿，生命/资源/奖励同次回执提交。运行时上传保留服务端装备BUFF，客户端不能创建或删除。临时盾→装备盾→MP→生命保持原有客户端计算、服务端校验和回执提交分工。
- skills：SkillCosts统一预览/普通与装备起手/职业起手的资源及冷却。SkillStartService在准备合法落点、资源及来源后原子提交，再广播闪现成功；有效主动起手才计印记。装备来源等级与魔法加级分开，基础三技能标签不包含装备技能；已绑定技能卸装不删绑定与剩余冷却。StaffBolts用共享命中入口，BasicAttackService校验直线路径、时间和首次碰撞。
- dungeons：目标快照增加双防/四抗与精英能力；仅新生成精英抽取一种，既有存活实例保持空能力。
- economy：商城仅契约，购买由库存事务同笔提交金币/到期点。SaleScreen使用服务端分块报价，客户端只提交选择键；完整物品快照留服务端校验，全部验证成功一次删物加金币，receipt去重。
- bootstrap只装配公开端口/消息/页面；普通内容没有修改受保护架构、传输容量、统一属性公式或事务基础设施。
