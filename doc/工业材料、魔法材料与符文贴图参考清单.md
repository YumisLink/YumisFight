# 工业材料、魔法材料与符文贴图参考清单

状态：**100 项工业图标已采用原版或模组底图制作，其余保留调查与重绘建议**。粉末显示名统一使用“XX粉”；既有物品 ID 和配方沿用原登记，新增盐水制镁与 T6 铌钛镁合金压层路线。

制作、重绘或复用本清单中的贴图前，先读 [贴图创作](创作指南/贴图创作.md)，按其中的原版基底与模型保留要求执行。

## 范围与现状

- 工业主清单来自 `tools/industrial_materials.json`：123 种工业图标中，66 种沿用原版或 Mekanism 底图，6 种导体、组件和点火芯图标使用其他独立底图，20 种燃料棒、胶囊及核素热源和 8 种魔能水晶使用独立的 16×16 源稿，其余 23 种保留 32×32 图；另有 5 个 `prospector_t1`～`prospector_t5` 工具帧保持原样。清单还登记十二种桶的独立图标，共 140 项。
- 工业原料方块、矿物、流体桶和魔力植物另列；魔能水晶的物品栏图与手持／展示的三维模型贴图分开列出。
- 已登记的符文物品只有空白符文和炎符文，目前分别直接使用原版纸与火焰弹模型，没有独立 PNG；清单中的新 PNG 为建议目标，不代表现在已经存在。设备和世界装饰中的符号另列为关联范围。
- 工艺精华与固定宝石属于装备工艺材料，现用原版图形。它们也与“魔法材料”视觉有关，因此作为**建议纳入、可单独确认的扩展范围**列出，不把它们混同为工业材料。
- 基底换色材料的编辑源是 `tools/industrial_material_bases.aseprite`，制作入口为 `tools/draw_industrial_material_bases.lua`；导体、晶格、控制件、点火芯及外壳的 16×16 源稿为 `tools/industrial_component_bases.aseprite`，绘制入口为 `tools/draw_industrial_components.lua`；燃料棒、胶囊与核素热源的编辑源是 `tools/nuclear_fuel_rods.aseprite`；魔能水晶的 16×16 编辑源为 `tools/energy_crystals.aseprite`；其余材料保留在 `tools/industrial_materials.aseprite`，绘制源为 `tools/draw_industrial_materials.lua`。源稿的命名帧合并登记在 `tools/industrial_materials.json`，统一导出入口为 `tools/export_industrial_materials.lua`。按当前正式引用编辑，保留其他任务改动。
- 参考图位于 `temp/`，为本机材料；下方每个编号同时保留上游来源。用于选择配色、质感和合适的复用素材，具体用法遵循上述贴图创作规范。
