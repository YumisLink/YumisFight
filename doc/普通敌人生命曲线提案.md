# 敌人统一生命成长

2026年10月30日。用户最终确认从1级开始，所有敌人每级生命×1.08，不分段；倍率预先缓存，生命求值直接查表。该规则已写入代码，主源及客户端编译通过；尚未打包或实机验证。玩家公共规则见[副本与敌人](../playerread/副本与敌人/README.md#敌人生命成长)。

## 当前实现

[Target](../src/main/java/cn/yumis/fight/modules/dungeons/api/Target.java)按1级基础生命取普通怪50、副本Boss与末影龙2,000、凋灵1,500，统一乘同等级倍率。精英、强壮力量、难度、物种和组队继续使用现有倍率。训练沙袋提前返回固定10,000基准，不参与成长。

1～80级倍率保存在类私有的静态double数组，长度取角色公开上限CharacterRules.MAX_LEVEL。首次类加载时，第1级倍率1，之后以先前倍率×1.08填表一次；每次health求值仅取HEALTH_GROWTH[level−1]并做乘法，不调用pow，也没有按等级循环。数组不进入存档或网络字段。正式副本定义与角色有效等级均限定在1～80级。

没有修改属性通用公式、客户端计算/服务端提交分工、伤害截断、敌人防御/抗性/攻击成长、奖励、存档代际或装备定义。已有敌人继续使用原生命百分比记录，不扫描或重新生成实例。
