# 剑魂伤害调整与推算

2026年10月29日。用户确认按技能解锁等级递减增强，并授权修改；本次采用当前已开放的1～50级技能范围。规则的玩家说明见[技能Wiki](../playerread/技能/README.md#伤害权值)。本文件为静态算术推导，不是实机测量或轮转验收。

## 调整范围与计算条件

技能自身伤害参数在原有权值校准后乘解锁档位倍率；普攻按最低档乘10。全局基数仍为0.5。仅伤害参数变化，非伤害增益、段数、攻速、冷却、MP、控制、范围、敌人生命和防御沿用当前值。当前尚未开放的50级以后技能不因本次修改而开放，未来解锁等级高于50的伤害档位固定为3倍。

当前格式装备实例、词条随机分位、基础成长快照、孔位、加工和玩家投入均保留；不迁移或重抽。装备固定附伤本身不乘新增倍率；与来源伤害相关的职业伤害仍使用该来源的系数。基础技能与高级技能的参考贡献比例会变化，例如鬼斩与暴风式的原权值1:10变为增强后的10:30。

1级为转职前鬼剑士、初始1级普通太刀；60/80级为剑魂、同等级普通光剑。仅使用这把武器与角色自然属性，不加自由属性点，无其他装备、随机词条、宝石、临时增益、暴击或感电追加。各技能逐项按该角色等级的自然可学上限；60/80级武器精通分别9/13级。不是同时加满所有技能的合法SP配装，不能把表内各项之和当作真实一轮技能循环。

普攻列完整攻击周期：转职前一击，光剑精通双击合计；鬼斩列满蓄，两倍基础段；其余列全部斩击与终结直接伤害之和。小数只在表格显示时四舍五入。

正常敌人条件：同等级、单人、普通难度、非精英、无特殊词缀，物种生命/攻击倍率1、各元素抗性0；不触发等级差修正。1/60/80级敌人生命分别50/1,525/2,025，物防30/502/662，魔防20/315/415。实际野外物种、难度、组队及精英状态会改变生命。

下表“零防”是完整命中理论伤害；“扣防后”是该理论伤害经过敌人防御后的结果，包含超杀潜力。活体敌人提前死亡会中止后续段数，实际扣血最多是其剩余生命；没有新增运行时伤害截断。

## 额外影响与限制

- 60级普通敌人1,525血，光剑普攻每击扣防后约992.85，双击约1,985.71，可在一个周期内击杀；80级敌人2,025血，每击约1,420.93，双击约2,841.86，同样一个周期。均不依赖感电。
- 暴风式60/80级扣防后完整命中理论约389,545/877,239，远超同级普通怪生命；该怪会提前死亡，不会吃满25段。即使增强前，60级暴风式完整直伤潜力也已很高，本次并未证明整体高等级平衡。
- 破极兵刃不因10→3倍曲线提高BUFF百分比。若另外投入到60/80级自然上限并开启，对本表直接伤害分别再乘约1.371394/1.584396；这是施放期间增益，不是120秒平均覆盖。
- 感电的具体追加量取决于先前5秒内命中、触发和来源系数，未加进本表；装备独立附伤、暴击、加点和其他装备也未计入。因此本表不能代替个人装备面板、实测或完整轮转。
- 120秒校准基数保留原模型；新倍率在校准后施加，波动眼非伤害强化比例保留，不反向重新归一化来抵消本次增伤。所有伤害技能的自有通道（含持续伤害、资源增量、终结）按自身解锁档位增强。
