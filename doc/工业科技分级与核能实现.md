# 工业科技分级与核能实现

本批按2026年11月4日本聊天已确认的工业方案实施，包含后续的T6人造恒星、核心主色、碰撞和明确九宫格形状修订。全部为industry应用内容；装备制作器只调整本模块方块的包围盒。没有扩展受保护架构、事务、网络传输或统一属性公式。玩家权威说明为[科技等级与能源](../playerread/工业/科技等级与能源.md)。

## 数据与资源入口

`tools/industrial_technology.py`拥有明确的制造形状、科技分级、升级成本、核心色板、核燃料与聚变配方。`industrial_expansion.py`生成原有矿藏、合金、工艺液后调用此入口；`industrial_resources.py`完整生成时经扩展入口收口。删除原先机械平铺材料的`industrial_crafting.py`，不再自动把材料清单填满九宫格。美术源`industrial_arcane_art.lua`读取相同色板。

打包目录`assets/yumis_dungeon_and_fight/industry/technology.json`登记材料／液体等级、设备科技与工艺上限、固定碰撞盒、升级扣料和配方能耗档次。`IndustrialTechnology`提供只读访问；`IndustrialUpgradeCosts`从目录消费制造生成时登记的同一份成本。实际配方位于`data/yumis_dungeon_and_fight/recipe/industrial`。

色板中间色依次为T1铜BE7954、T2青42C8C1、T3钛银90A6BD、T4暗蓝3E596E、T5紫8B65BC、T6金E5B83C。机身金属、石底和旧金色饰边按科技核心着色，功能宝石和火焰不改色；保留原呼吸帧及动画元数据。人造恒星和新增专机暂复用现有几何，专属3D建模未完成。

## 科技与制造

功能档次、科技等级、工艺能力独立。原有五级矿机与并行设备仍为1～5档；人造恒星功能档5、科技T6，不能把T6塞进现有五元素速度／并行数组。铱是T5材料、T6开采能耗；钛与冷却液同为T3，水为T1。

T1基础材料直接起步，不注册T1科技方块。T2～T6的科技方块各使用三种材料、每种4份，1块拆2核心；机外壳使用同级方块1、核心1、上阶段机架2。T6机架仍用精密机架。具体材料只在玩家权威表与生成源维护。

升级采用` C /FMF/ S `：C目标科技机外壳1，M前级机器1，F导魔件2，S上阶段机架1。T2～T4使用导魔组件，T5使用秘银导魔组件。原地升级手持C，消耗除M外完全相同的材料，保留原库存、液体、余额和在制批次。工具升级使用独立的玻璃、机壳、前级工具与两侧线路形状。

常规机身采用`MFM/CSC/MMM`，储罐采用`G G/GSG/IBI`，抽水采用` C /GSG/MBM`。核反应堆`TIT/CSC/TNT`加入高纯铱和T5机壳；人造恒星`LCL/ASA/LCL`使用约束晶格、超导控制、恒星合金和T6机壳。核能／RTG核心也改为屏蔽外框、中心功能件的完整九宫格。压块为3×3、拆包为单格，权杖为斜线，硫化物为横排。工业目录不再保留无序工作台合成。

零件手工配方与自动锻炉配方从实际图案计数同步。导魔、秘银导魔和超导控制去掉额外水晶物料；耐热／精密机架为对称框架，陶瓷各4份。高级机壳与升级链不要求旧魔法石；时空石的旧魔刹石原料换为晶格基体。

T2方块由1级锻炉加工，依次推进至T6方块由5级锻炉加工。T3普通矿物加工至少3级、T4至少4级、T5至少5级；金属锭、高纯锭仍受此限制。工业熔炉先选专属配方，原版熔炼回退也按材料等级校验能力并为高级材料计算相应费用，避免石英等已有熔炼材料在所有工业等级都被拒收。生产下一阶段合成材料允许使用上一阶段设备，例如五级锻炉制造T6恒星材料，不用材料显示等级无差别阻塞进阶。

专用精炼机T2／能力5、反应釜T3／能力5、混合器T3／能力3、蒸馏T3／能力4、成型T3／能力5、离心T4／能力5、活化T5／能力5。保持单型号单线，后续是否增加多级专机尚未实施。

## 能量与采矿

矿藏规则版本3将`power`删除，唯一字段为一批总量`energy`。`MineralCatalog`默认值读取同一个打包工业规则，不维护第二套矿物费用表；不解码旧规则。整包`ApplicationRules.DATA_VERSION`升至11，协议与机器schema维度独立。

设最低矿机L0、当前等级L、原一级时长ticks、丰度r（普通1）、冷却c（无1／水1.5／冷却液2.5）、超速芯片n：

```
一批时长 = ticks / (20 × L × r × c × 1.5^n)
一批耗能 = ceil(E0 × L / L0 / r / c) × 2^n
```

E0的完整表见[玩家采矿费用](../playerread/工业/科技等级与能源.md#采矿费用)。保留矿藏概率、产量、无限储量、丰度和耗液倍率；运行时仍用Fraction，不把1000/3tick的辉钼／锆石工艺截断为整数。JEI和选矿页按最低矿机展示精确基准秒数。

普通丰度无芯片的三级钛20秒14418魔能；五级铱24秒648000000魔能，即27000000/秒。玩家任何工具手挖T4以上原矿不掉落，在精准采集判断前拦截；自然矿脉继续生成以供辨识，深层开采仍由矿机提供。

基础预算按配方工艺的最低设备、普通单线和无芯片计算：T1为1～20/秒、T2为20～200、T3为200～2000、T4为2000～30000、T5为30000～300000，参考值10／100／1000／10000／100000，复杂度0.75～1.25。T1/T2既有配方只下调；矿物、混合器、泵、储物升级和燃料另按明确值。并行仍增加整机吞吐和用电，不额外增加每批产量。

基础碎石50/100tick，普通熔炼50、一级200tick配方为2.5秒，抽水10/秒、1B/秒，收种20/株，两类运输5／25／100每次成功事务，通货600/枚。冷却液2500/100tick，即500/秒。混合器保留超速插件，每件速度1.5、批次能量2、每秒需能3倍；其他插件合同不变。

最低闭环为一级煤矿机、燃煤、T1信标和回煤物流，起始手动投入煤。普通煤20秒／50魔能；燃煤60/秒、每煤32秒，矿机加回送费用可持续由本机供能。抽水与冷却不作为启动要求。这里只完成预算推导，没有声称完成实机自动化验收。

## 按设备能力结算

有`FLUID_PROCESSING`能力的机器继续渐进：包含矿机、锻炉、混合器和各带液体专机，即使当前工艺没有用液也按机器分类。整批固体托管，工艺液预留，按进度反应；按完成的整件固体／液量入槽。

无液体加工能力的碎石机、熔炉、通货机和成型装配机改为读条完成时扣左侧原料并整批出货。开工锁定具体资源及组件快照，玩家可在同一线移动同资源；不足立即取消读条，已耗魔能不退。最终扣料和所有产物在同一库存事务完成，输出失败回滚；拆机不退从未托管的原料。

schema4增加显式`deferred_inputs`所有权标记；当前格式已有在制批次仍依开工时的progressive／托管快照结束，不从显示文本或当前机器类型推测旧批归属。未知旧schema仍拒绝，不新增迁移或旧字段转接。通货随机结果开工锁定，取消读条已付费用不退。

未锁定工艺保留现有排序、输入轮转与同产物较少材料优先；除矿机必须选矿外，专机可自动匹配并选择锁定。自动投料和入液按同一配方目录保留各材料位置，避免一种材料占满其他材料槽位。

## 核燃料、热源与人造恒星

铀六道加工、三条热源、氘氚与盐水线路见[玩家能源流程](../playerread/工业/科技等级与能源.md#铀燃料与核能)。铀燃料棒800秒／8640万、水100B/秒，燃尽产乏燃料；RTG三密封热源均800000秒，功率108／540／2160；聚变胶囊20秒／10亿，冷却液100B/秒，燃尽返空胶囊。

发电机开工快照包含燃料总量、剩余tick、能量、流体速率和产物；读档及规则重载不改变当前燃料承诺。最后一tick的流体消耗、燃料进度和乏燃料／空胶囊输出使用同一工业库存事务；输出满则停，不丢联产物。

人造恒星结构5×5×5、97个T6机外壳加控制器、内部27格空气。`IndustrialStructures`同一格子定义供完整性、影响范围和逐层查看使用，锻炉保留3×3×3和25个同级机壳。区块未加载与真实缺失分开，未加载只暂停。

每次点火消耗T6点火芯1和1亿魔能，分次保留已充量，电网先满足原有加工和供液任务，再将余量交给点火；充满时点火芯与首枚聚变燃料在同一事务消耗，下一tick开始输出。缺料、缺冷却和结构损坏熄火、再次付点火费用；剩余燃料保留。人工停机、卸载和重启保持已点火状态，不重复收取、不补离线产量。单模组单JAR和原电网分配语义不变。

## 模型碰撞

普通机器使用模型主要实体的粗长方体，忽略薄符文，按朝向旋转；选择与实际碰撞共用盒子。水晶依用户最后修订采用“底座＋中央水晶”两盒，中央盒覆盖上下浮动范围，周围装饰不碰撞。风机三节各用静态机身盒，旋转叶片不碰撞。装备制作器在equipment自己的方块内使用1/16至15/16的本地盒，不跨模块读取工业实现。

## 工业资料依据与游戏抽象

铀工序参考开采、矿物浓缩、转化、富集、燃料制造的阶段划分，映射为现有机器的六道游戏加工，材料数量与能量均为游戏设定。[NRC核燃料循环阶段](https://www.nrc.gov/facilities-safety/fuel-cycle-facilities/stages-of-the-nuclear-fuel-cycle)

Pu-238线路参考专用靶件准备、辐照、化学处理与热源制造的分工；游戏以虚构前驱组件和现有工艺液表示，不实现现实靶料配方或操作条件。[ORNL生产流程概述](https://www.ornl.gov/publication/coordination-plutonium-separations)

Cm-244资料说明其来自核转变并经放射化学处理；游戏将其抽象为乏燃料冷却、后处理与含锔料分离。[NIDC Cm-244资料](https://www.isotopes.gov/sites/default/files/2021-02/Cm-244.pdf)

Th-228具有专门生产和分离流程。游戏采用专用前驱件的辐照冷却路线；将其作为RTG燃料是本聊天批准的游戏设定，不等同于现实常规用途。现实Pu-238的太空热源用途与本游戏统一燃烧时长分开。[NIDC Th-228资料](https://www.isotopes.gov/sites/default/files/2025-09/Thorium-228%20Product%20Information%20.pdf)、[NASA Pu-238热源](https://science.nasa.gov/planetary-science/programs/radioisotope-power-systems/about-plutonium-238/)
