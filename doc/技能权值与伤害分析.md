## 规则与参考模型

唯一全局基数在 `data/yumis_dungeon_and_fight/rules/skills.json`，当前 `baseWeightDps=0.5`。目标为“职业增益前最终攻击面板 × 120 × 基数 × 技能权值”。面板包含力量／智力，参考面板1000、60级自然力量197与智力133、不分配额外主属性、零防零抗、无暴击和装备附伤。

每个技能独立取60级自然可学等级；从0秒冷却就绪起，只累计 `[0,120)` 的命中，持续尾伤也按时间过滤。参考资源可支付，刻印3枚、血刹15层；狂战士双刀与40%生命，职业增益按窗口覆盖率计入。每个技能的动作和命中参考时间由内容登记，剑魂的武器速度、加段、太刀流血及条件增伤、光剑感电、短剑剑气和巨剑增伤一起校准。概率效果采用有限窗口数学期望，不运行战斗随机数。

权值及玩家规则以[技能Wiki](../playerread/技能/README.md)为准。噬灵额外0.5独立校准，自己阵内合计3，当前自然红阵收益包含在阵内目标中；阵外和阵内按60%覆盖参考约2.4。卡洛包含冥炎与终结。波动眼炸眼9，增益新增3：使用同一火波、冰波、地裂、空档普攻时间轴核算增量，20秒强化周期按0／90秒起手。当前推导强化参数约116.17%，与全局基数无关，基础伤害随基数同比变化。

校准只生成基础系数，不用玩家实际装备的攻速、减冷却、等级或伤害重新反算。伤害参数保留每级12%成长，实际装备继续产生收益。装备独立固定附伤在后续原有伤害公式中计算，不乘技能全局基数。未开放的后续技能仅提供权值规则，没有开放二觉／三觉内容。

## 模块合同

| 内容 | 所属入口与职责 |
|---|---|
| 权值及时间轴 | `skills/api/SkillBalanceProfile` 提供权值、参考周期、增益条件和命中列表；`BuiltinSkillBalance` 登记当前内容 |
| 职业参考 | `SkillBalanceStyle` 登记默认武器、职业参考倍率、普攻时间轴和武器固有效果；通用 `SkillBalance` 按登记项计算，无中央技能／职业选择分支 |
| 伤害参数 | `SkillDefinition.damageParameter` 声明随等级和基数成长的自有通道；`SkillParameters` 先解析基础平衡参数，再应用装备参数 |
| 条件变体 | 内容注册参数处理与起手变体，噬灵、阵内额外倍率、波动眼参数进入起手快照 |
| 资源快照 | `CareerRules.resourceSnapshot` 从已解析参数取得刻印增量、旋转／终结、持续伤害和血层增量，不用硬编码覆盖基础系数 |
| 普攻 | `BasicAttackProfile` 携带起手间隔、段数、自有伤害系数和波动眼参数；服务端确认后客户端使用同一快照 |
| 装备授予与绑定 | `SkillLearning.effective/canBind/apply` 使用有效装备来源；角色模块通过 `SkillProgression` 端口传递属性，服务端再次校验 |
| 分析 | `combat/api/client/DamageAnalysis` 持有本地轮次、稳定来源和回执凭据；`CombatPrediction` 仅把确认的实际扣血送入分析 |
| 分析页面 | 战斗模块的 `DamageAnalysisPanel` 通过现有页面登记接入；角色页按钮只负责导航 |
| 伤害显示 | `NumberText.damage` 使用 HALF_UP 四舍五入和完整十进制整数；数值累计仍为 double |

`ApplicationRules` 整包包含技能规则，候选解析和数值有效性验证全部完成后才发布。`ServerApplication` 持久记录 `definitions/skills` 并同步 `skillBalanceRules`；规则包版本为9。失败保留上一完整包，已起手的技能、普攻和投射物持有旧快照，后续起手读取新包。本任务没有修改受保护底层文件，也没有改变客户端计算、服务端校验与提交的分工。

## 技能行为

- 鬼印珠：`3+5×刻印数` 段，玩家／目标／生命代际共享350毫秒时钟；重叠珠按应触发时间排序，未触发段数留队。客户端维持队列与可刷新视觉，服务端续存起手快照；目标死亡、代际或场景改变时结束。
- 不动：按起手实际耗印数绘制球体，3秒引导，每球850毫秒一击并错开。总旋转次数 `floor(3×球数/0.85)`，3印10击加一次爆炸；标准3印旋转60%、爆炸40%。释放速度压缩动作与间隔，段数不变。
- 爆炎：起手记录准星方向10格内合法终点、弧高1.5格、距离／15的飞行时长。客户端推进抛物线，服务端分段检查碰撞与捕获并执行安全移动，确认落点后客户端提交一次半径2.5爆炸。沿途宽5格；Boss或普通击退抗性100%的敌人免抓，范围内仍承伤。移动受实际碰撞约束。
- 血刹：仍保留60秒准备及终结，最多20层，15层对齐10；基础和每层的原线性比例一起缩放。所有确认的有效伤害均可蓄血，首击可蓄，此后每玩家500毫秒一次，多目标、多段或重发不额外蓄层。
- 学习：去除技能固定等级上限，保留解锁后每5个人物等级再学一级、现有SP及80级人物上限。

## 伤害分析与生命周期

Ctrl＋】只控制开始／停止，左右Ctrl均可、长按不重复、空手可用。开始清空上一轮并计时；停止冻结时长并保留结果。角色页进入分析页面不会修改轮次。结果按伤害排序，显示技能、整数伤害、占比、有效命中数、时间和整数DPS。

实战只消费本人有效伤害回执，用实际生命扣减比例乘该操作的目标生命基准，排除超杀、拒绝和重复回执。普通攻击单独列出，附伤与感电归触发技能；流血在附着时记录稳定技能来源，清理施法表后仍可归属。沙袋通过独立训练入口累计，不伪造实战回执。

提交操作时固定轮次和来源。停止后只补记停止前已提交的有效回执，新轮次拒绝旧轮回执；角色资源／属性快照刷新会移除预测，但单独保留分析回执凭据。首次有效命中确定实战／沙袋类型，遇另一类型停止并保留原结果。换地图、维度、进出副本、断线停止并清空；死亡停止保留，复活不自动开始。分析状态不参与战斗权威或存档。
