原始生成/升级基线保留，通过当前定义倍率只应用一次。来源锚点记录实际有效倍率，装备与宝石分别取自身等级；保留原分位、腐化、来源和投入，无法确认来源的当前实例保留快照及问题标记。停止投放不等于停用已有实例。

## 2026-10-30 本机收藏展示

词条宝典按AffixGeneration的真实候选和装备资格构建普通随机池并集，当前属性/EXTRA与4个技能等级共46项；不改变任何定义ID、范围、revision、资格、权重、投放或已有实例。法师之血、具名独特、基础、固有及退役项不列入宝典。收藏以稳定定义ID保存本机配置，仅给装备、宝石、加工结果和出售详情加星；未识别/退役收藏ID保留，不恢复投放。生效与成长规则仍以上文为准。

## 2026-11-03 技能加级与部位筛选

新增 `family_sun_moon`、`family_summon`、`family_magic`、`family_physical`、`family_passive`，均使用现有SKILL_FAMILY运算、fixed_rank组与随机+1～3级规则。日月系按日月技能ID归属，召唤系沿用SUMMON归属；魔法/物理按技能既有攻击类型判定，被动按技能的passive定义判定。加级不解锁未学习技能，转职自动获得的日月流转按已有1级参与计算。按用户补充，流转接受被动与日月系加级，不接受魔法/物理加级，也不接受尼巫原有tag/magic来源；其他技能的既有加级资格保留。

技能加级生成组仍只对武器提供原总权重15，现有4项与新增5项共享该组。新生成、追加和替换时，只要已有SKILL_FAMILY便不再生成另一条，包含锁定项及允许重复属性的路径。当前格式已有多条实例保留、生效和成长，不在读取时删除、重抽或改写其来源快照；不改变词条ID与已有revision。

宝典从同一真实候选并集增加到51项，部位筛选与搜索、收藏取交集。装备模板、数值、随机条数和未投放品质资格不因本批恢复。玩家规则以[技能等级词条](../playerread/词条/README.md#技能等级词条)为准，编译与未测边界见[本批说明](日月技能与界面词条调整.md)。

## 2026-11-03 所有技能攻击力语义

用户明确“所有技能攻击力提高X%”按技能专属独立乘算，各来源分别乘(1＋X%)。现有专用SKILL_ATTACK运算接入allSkillAttackProduct，不以显示文字推断效果；原通用伤害MUT与既有skillProduct处罚语义保持。当前没有新增自然随机词条或复用旧ID，没有需要重抽的装备实例。完整快照、附伤与普攻边界见[本批说明](恶魔猎手与武器扩展实现.md)。

## 2026-11-03 技能词条武器限制

本节收紧上文技能加级的生成范围，玩家规则唯一说明见[技能等级词条](../playerread/词条/README.md#技能等级词条)。装备模块按武器类型提供资格，不读取持有者职业；鬼剑士与魔法师沿用JobCatalog公开武器目录，浩劫及未来两系固定限定WARGLAIVE。MAGIC、PHYSICAL、PASSIVE仍可在所有武器生成；未知家族默认不投放。非武器不生成技能加级。

| 稳定ID | 家族／效果来源 | 本批状态 |
|---|---|---|
| family_sword / family_ghost / family_wave / family_blood | 原SWORD / GHOST / WAVE / BLOOD归属 | 限鬼剑士武器；原ID、revision与效果保持 |
| family_sun_moon / family_summon | 原SUN_MOON / SUMMON归属 | 限魔法师武器；原ID、revision与效果保持 |
| family_element | ELEMENT，沿用技能现有归属，含杰克爆弹与日月技能 | 新增随机+1～3级，仅魔法师武器 |
| family_havoc | HAVOC，已实现的9项恶魔猎手基础／浩劫技能在内容定义中登记该家族 | 新增随机+1～3级，仅战刃；沿通用家族加级计算，不新增中央技能分支 |
| family_devourer / family_vengeance | DEVOURER / VENGEANCE | 用户确认先预留待投放；retired=true关闭生成与宝典，不新增对应技能，未来仅战刃 |

所有已投放技能加级仍共享原生成组总权重15和单条名额，+1～3级范围、锁定及加工资格保持；追加、替换、允许重复属性的路径均先经过武器筛选。宝典使用同一真实候选并集；新增两项开放词条后为53项，预留两项不计入。

武器限制只决定后续生成，读取、效果、成长和神圣石不执行该筛选。当前格式已有跨职业／多条词条继续保留原来源、等级、分位与效果，不删除、不重抽、不迁移旧格式；名称及说明更新不提高效果revision。跨模块端口见[模块接口](模块接口与扩展.md#2026-11-03-技能词条武器资格)，未测边界见[待测试清单](待测试清单.md#2026-11-03-技能词条武器限制待恢复测试)。
