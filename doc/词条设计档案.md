# 词条设计档案

2026-10-28。本档案统一效果语义、用词及装备来源；装备身份与基础见[装备设计档案](装备设计档案.md)，统一公式见[数值设计规范](数值设计规范.md)。本批已编写实现，13件来源装备仅创造获取；炫纹相关为未实现。编译与打包不代表玩法验收通过。

## 设计去重与正式用词

新增前必须同时检查本档案、装备档案和实际效果定义。语义签名为“作用对象、作用域、触发、阶段、运算、元素/技能标签、限制”。同签名仅区间、数值、正负或来源不同，归入同一效果族，共用处理器；数值区间不是新机制。装备档案引用本档案效果，本文反向记录来源。旧ID和已生成实例不因去重删除、合并或重抽。

本次去重结果：别云的本件物攻复用既有FLAT/PERCENT；小丑帽、皇冠及掉宝宝石复用FLAT(DROP_RATE)；皇冠四抗复用ALL_RESIST_FLAT；尼巫攻速复用FLAT(ATTACK_SPEED)；经验、回魔、冷却恢复共用CHARACTER_PERCENT。来源ID保留各自区间，未新增重复的计算规则。黄金BUFF的掉宝是角色ADD，和装备本件固定掉宝的作用域不同；印记与精英狂暴共同使用伤害MUT。

统一字段：所有元素抗性、掉宝率、角色经验获取、魔力回复速度、冷却恢复速度、技能释放速度、吸血值。吸血率为派生概率。负数只显示一个负号，例如“所有元素抗性−25”“魔力回复速度−40%”。装备词条编号只用于档案排列，不展示玩家。

## 数值效果族

以下全部来源ID前缀为 `unique/`，普通随机池不抽取这些来源配置。范围使用非腐化原始单位；标“区间”者可神圣重洗及腐化数值乘算；固定值不参与腐化随机倍率。

| 统一效果族 | 来源配置ID | 原始区间/固定值 | 装备或宝石来源 |
|---|---|---|---|
| 本件物攻百分比 PERCENT | bylle_physical_percent | 区间150%～250% | 别云剑-无用 |
| 本件物攻固定值 FLAT | bylle_physical_flat | 区间400～800 | 别云剑-无用 |
| 本件攻速固定值 FLAT | niwu_speed | 固定40个百分点 | 尼巫的职责，叠加棍棒自身10 |
| 吸血值 FLAT | life_steal | 区间80～160 | 鲜血誓言 |
| 掉宝固定值 FLAT | clown_drop / crown_drop / gem_clown | 区间−120～120 / 区间10～15 / 固定15 | 华丽的小丑帽 / 皇冠 / 小丑之石 |
| 本件四抗 ALL_RESIST_FLAT | crown_resistance | 一次抽值，四抗各−35～−15 | 皇冠 |
| 角色经验获取 MUT | experience_gain / gem_crown | 区间0%～50% / 固定10% | 皇冠 / 皇冠之石 |

## 固定机制参数族

这些值属于装备效果合同，不注册为玩家AttributeValue。表内“区间”允许神圣重洗；开关、技能等级、层数和固定参数不洗。

| 来源配置ID | 正式作用与参数 | 来源 |
|---|---|---|
| gem_amplification | 本武器镶嵌宝石的数值效果提高200%～300%（原值×3～4）；整件一个区间抽值；不放大规则开关或授予次数 | 威利的戒严法杖 |
| fire_after_damage | 造成伤害后，额外造成相当于该次伤害60%～100%的火属性伤害；完整结算见数值规范 | 天脊乾坤剑 |
| fire_conversion | 保留火强化，其余三强化按固定33%转为火强化并清零 | 天脊乾坤剑 |
| fire_only | 无元素转火；混合元素含火时只保留火，不含火的分量禁止 | 天脊乾坤剑 |
| block_elemental | 禁止所有带元素标签的伤害分量，无元素物理及魔法伤害保留 | 别云剑-无用 |
| golden_power | 有效本人击杀加1层黄金之力，上限255，每层角色掉宝ADD+1；20秒无有效事件整组清除，满层刷新计时 | 波利斯的黄金杯 |
| imprint_power | 成功施放主动技能加1层印记之力，上限18，每层伤害MUT+1%；新层计入本次快照；20秒无有效事件整组清除 | 罗塞塔石碑 |
| hero_power | 击败精英继承对应力量；区间持续10～60秒；不同类型共存，同类型刷新 | 英雄王的象征 |
| magic_ranks | 固定所有可用魔法技能等级+3，不让未学普通技能凭空解锁 | 尼巫的职责 |
| magic_cooldown | 魔法技能最终冷却减少区间1～2秒，在冷却倍率后扣除，最低0 | 时空之肌 |
| grant_blink | 授予主动魔法技能闪现；来源等级规则见技能Wiki | 时空之肌 |
| kill_recovery | 有效本人击杀回复区间最大生命2%～5% | 鲜血誓言 |
| life_cost | 原MP消耗按区间100%～200%改付生命；不经过盾/MP抵伤，支付后至少1点生命，失败整次不施放 | 鲜血誓言 |
| inverse_resists | 本人命中时目标四抗视为相反数，不改写目标原抗性 | 芮兹的第六元素 |
| resistance_cap | 自身四抗最终上限，整件随机同一个区间−100～0 | 芮兹的第六元素 |
| mana_share | 盾后伤害的区间50%～100%由魔力承担，1MP抵1伤害；有效比例最多100%，保留原词条值 | 魔力流转 |

黄金、印记与四类英雄力量均带装备来源，卸装/资格失效、死亡、退出清除。黄金本次击杀新增层从之后击杀的掉落生效。失败施法、普通攻击、被动触发和技能段数不加印记。

精英力量：强壮最大生命MUT+50%；狂暴伤害MUT+30%；坚韧双防MUT+50%；元素守护四抗ADD各+30。新生成精英等概率一种，保留原精英生命×3、攻击×1.5；旧存活精英不补抽。

## 固定附伤与比例追加

既有EXTRA统一描述“附加X～Y点火属性伤害”（其他元素替换名称），上下限相关联，沿原附伤规则结算。比例追加单独使用fire_after_damage，不与固定附伤归并；其基数、二次防御、元素和不递归规则以数值规范为唯一说明。

## 加工、保存与宝石

神圣石覆盖所有品质的明确可洗数值；不改类型与固定值，法师之血独立重洗。破溃保护删除/替换，不保护数值刷新。腐化先按神圣规则重洗，再每条可洗效果独立乘80%～140%；负数直接相乘、关联值共用倍率，原分位和腐化倍率独立保存。定义同步保留两者，未知当前快照不猜测。仅兼容当前代际和装备version9。

皇冠和小丑帽固定提炼对应宝石；来源装备当前等级成为宝石等级，仅防具可装。消耗整件和1枚拆解石，源装备及其中宝石全部销毁；同件不可重复效果宝石，覆盖销毁旧宝石。其他11件与旧具名装备未开放提炼。未来增加来源先按本档案去重，不复制同义处理器。
