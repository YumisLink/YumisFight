# 觉醒塔 50 层与卡牌

## 场次规则

每座塔都有 50 层，使用地狱难度并复用本塔的同一间战场。敌人的个人结算等级始终取当前玩家等级加 5。62 级和 65 级玩家面对同一只怪时，分别按 67 级和 70 级计算攻击、受击及显示，服务端归并双方伤害份额，共享一条剩余生命比例。角色升级后下一次计算读取新等级。召唤物和伤害统计使用同一塔内等级规则。[目标等级](../../src/main/java/cn/yumis/fight/modules/dungeons/api/Target.java) [伤害份额接收](../../src/main/java/cn/yumis/fight/modules/combat/application/CombatApplication.java)

### 入场与回档

已有石碑直接进入 50 层爬塔，沿用开放入场。组队由队长发起，附近队友分别确认，开局锁定接受的名单。场次按队伍及本次入场标识隔离。入塔先显示塔名、楼层和场地效果，再打开初始选牌。已有卡牌时，单人、队长和受邀队员各自选择「清空并重新选牌」或「保留卡牌入塔」。清空在实际入场时生效，取消报名保留原牌。保留卡牌者用原构筑从第 1 层挑战，全程跳过选牌。普通层清场后推进到下一层，首领清场后等待有选牌资格的在线成员各自选定。

每次换层或从检查点重开时，在线参战者回到本塔的副本入口，显示当前楼层和场地效果。本人客户端补满生命、魔力、护盾、体力和饥饿值，重置技能与塔牌冷却，清除负面状态和元素积累。

第 50 层通关时完成当前觉醒任务的爬塔阶段，正式首领和临时占位首领使用同一通关事实。接着发最后一次牌作为构筑收尾，重新选牌者每局共有 11 次选牌机会。[觉醒任务](../../src/main/java/cn/yumis/fight/modules/quests/application/AwakeningQuestService.java)

队内成员倒下后观战，本层清场后复起归队。全员倒下则回到最近一次选牌完成后的楼层，例如第 15 层选完卡后第 19 层全灭，从第 16 层重打。已选卡和本局移除记录保留，重打段的编队和首领重新抽。怪物经验与掉落沿用个人结算等级下的地狱难度，重打新生成的敌人照常产出，同一次死亡仍沿既有幂等规则提交。[奖励规则](../../src/main/java/cn/yumis/fight/modules/economy/api/RewardRules.java)

原参战者离线时队伍继续。本局有选牌资格的玩家回来后按先后顺序补完所有错过的选牌，再进入当前层。未完成的选牌恢复原三张和剩余次数。最后一名参战者掉线时结束本局。

## 每人三选一

1. 进入场次和每次首领清场各产生一个选牌序号。客户端以场次 ID、玩家身份和序号保存待选三张卡、剩余刷新次数、已选卡和本局移除的卡 ID。重新打开窗口、改变分辨率或重复收到同一序号时恢复原选项。
2. 每个卡位可刷新 2 次，每次只变更该卡位并记录新的选项版本。普通、稀有、史诗和神话卡被选中或刷掉后，该玩家本局从候选移除该卡 ID。同屏三个卡位排除已显示的卡，牛奶保底可在多个卡位出现。各玩家独立保存排除记录。
3. 每次发牌和刷新先按普通 20%、稀有 30%、史诗 30%、神话 20% 抽档，再在该档可用候选中均匀抽取。该档没有候选时逐档降级，到普通档仍无候选就补一张牛奶。卡池暂缺稀有度时也使用同一套抽取规则。
4. 牛奶每次选取提高 10% 最大生命值，允许重复选取。牛奶始终可作保底，也可以用该卡位剩余次数刷新。刷新后再次出现牛奶时仍扣一次。每一轮只选一张，已选牌随玩家保存，中途离塔、通关和重新登录后均可使用。被动属性继续生效，主动技能沿原绑定触发卡牌效果，卡牌累计成长和自身冷却一并保留。塔的场地规则仅在相应塔内生效。

### 绑定技能与武器

| 占位 | 候选与结算 |
| --- | --- |
| 【特定武器类型】 | 用 `JobCatalog.weapons(jobId)` 沿基础职业取完整集合。鬼剑士为太刀、巨剑、短剑、光剑、钝器，包含该转职暂时不能装备的武器。抽中后存枚举 ID，用 `Weapon.title()` 显示名称。触发时按该次伤害快照的武器比对。 |

### 卡面与交互

备战时淡化场地，在屏幕中间并排显示三张卡。顶部显示当前目标，例如「第 16 层备战」。卡面从上到下放稀有度、卡名、效果说明、选择按钮。卡位自己的「刷新 2/2」放在牌面下方。刷新只让该卡位短暂翻面，另两张和焦点位置保持稳定。确认选择后显示卡名和「等待队友」，随后由场次进入下一层。

## 接入顺序

1. **房间与首领。** `DungeonService` 将石碑入场分派给 `TowerEncounterService`，按层记录清场目标和选牌阶段。普通编队和首领定义从 `TowerClimbEncounters` 读取。首领最终死亡提交后再发布新选牌序号。Boss 有独立的主目标 ID，召唤物保留攻击和清理流程。[塔场次](../../src/main/java/cn/yumis/fight/modules/dungeons/application/TowerEncounterService.java)
2. **选牌和场地属性。** `TowerClient` 持有本人的 `TowerCardDraft` 和 `TowerBattleState`。装配层通过 `TowerSkillTraits.choices` 提供技能资格，以 `TowerCard.pool(jobId, skills)` 取候选。角色同步、面板刷新和替代武器快照各自对新副本调用 `applyPassives`。先应用常驻属性和本局状态，再计算派生属性和场地速率。卡牌自身冷却用 `TowerCardEffects.cooldownMillis` 计算。当前候选及刷新记录随场次保存。已选牌、绑定、累计成长和卡牌冷却随玩家的牌组保存。 [本机组装](../../src/client/java/cn/yumis/fight/bootstrap/ClientSession.java) [卡牌状态](../../src/main/java/cn/yumis/fight/modules/dungeons/api/TowerBattleState.java)
3. **动作与战斗事实。** `TowerSkillCombat` 从技能实际放出、普攻周期、位移完成、有效伤害、实际扣血和正式击杀接入卡牌。各命中段对每个敌人独立计次，虹吸等单次施放上限按施放 ID 归并。卡牌附伤与锻炉塔无来源伤害使用 `CombatEffect.NO_TRIGGERS` 标记，基础受伤、死亡、掉落和清场照常结算，后续特效与卡牌击杀奖励被屏蔽。珠光护手的暴击属于本人该段伤害的计算。 [技能本机判定](../../src/client/java/cn/yumis/fight/modules/skills/api/client/SkillController.java) [卡牌事件](../../src/client/java/cn/yumis/fight/modules/skills/client/TowerSkillCombat.java)
4. **新增伤害段和数值通道。** 技能阶段原始物魔类型、伤害来源、第一段／衍生段资格应由对应模块显式提供。持续伤害、投射物和范围伤害沿正式计算、伤害分量与回执入口，按卡 ID 记录来源。由卡派生的伤害默认只触发明确允许的后续效果，防止元素追加、自身霜冻、额外暴击段和生成物重复触发。展示、预览和实际结算共用同一份伤害参数。[技能伤害规则](../../src/main/java/cn/yumis/fight/modules/skills/api/SkillDamageRules.java) [伤害计算](../../src/main/java/cn/yumis/fight/modules/combat/api/CombatRules.java)
5. **清理和放行。** 选牌后保留已确定的技能或武器，战斗中的护盾、层数和限时效果沿用卡牌原有时长与生命代际规则。入塔选择清空时连同原牌组一起清除，选牌窗口随场次关闭。按原规则逐批处理涉及的受保护文件。常规卡优先在负责该事实的业务模块补入口。

## 普通卡逐项实现

这些卡适合做场次被动。引用主动技能的卡由原施放或原命中触发，飞弹、爆炸和环绕物由被动自动生成。每张卡登记独立 ID、倍率、触发资格和持续期。表中写明需要确认的参数，以便确认后直接填进对应入口。

### 属性与伤害修正

| 卡牌 | 实现与参数 |
| --- | --- |
| 强力护盾 | 静态被动。现有护盾容量独立乘 1.30，护盾回复速度 MUT 加 0.50。 |
| 大力 | 静态被动。物理和魔法攻击力各加 0.20 MUT。 |
| 灵巧 | 静态被动。现有攻速面板加 60 个百分点，复用普攻周期与技能读取。 |
| 渴血 | 静态被动。按现有 `lifeStealRateAdd` 增加 0.0015，进入本来的吸血触发、结算和生命更新。 |
| 由心及物 | 静态派生。推荐取 `CharacterAttributes` 给出的职业成长基础魔力，按其 100% 加到最大生命。需确认是否也计入装备提供的基础魔力。 |
| 练腿日 | 静态派生。移速提高 50%，在正式移动入口将最终移动速度保底为默认速度。需确认根系塔减速、原版减速和施法锁定分别能否被保底覆盖。 |
| 唯快不破 | 静态派生。用最终移速倍率 `v` 得出伤害增量 `max(0, v − 1) × 0.5`，例如 1.20 倍移速带来 10% 最终伤害。需确认固定值伤害和衍生段是否纳入。 |
| 重量级打击手 | 静态派生。实时最大生命每满 100 点给伤害加 1%，推荐按 `floor(最大生命/100) × 0.01` 取值。与唯快不破共用正式伤害修正入口。 |
| 可靠武器 | 条件被动。匹配本次攻击快照的武器类型时伤害提高 30%，按现有「提高」乘区加入正式伤害修正。需确认召唤、装备附伤是否沿用出手武器资格。 |
| 杀意翻涌 | 条件被动。命中前目标预测生命严格小于 35% 时伤害总增 20%，该次伤害独立乘 1.20。重放使用该次命中的生命快照。 |
| 巫师式思考 | 条件被动。非被动技能的魔法主伤害段独立乘 1.20。预览与实际命中共用技能伤害规则，以每段实际物魔类型判定。 |
| 旋转至胜 | 条件被动。不动明王阵、献祭光环、眼棱和举刃对笑适用。技能伤害提高 80%，与其他伤害提高相加。冷却时间独立乘 0.50。预览与结算共用技能资格。 |
| 物理转魔法 | 类型转换。读取主动技能每段的原始物魔类型，物理段改用魔攻、魔防及魔法判定，转换段伤害乘 1.10。实际命中、延迟段和预览都读取同一转换结果。 |
| 魔法转物理 | 类型转换。原始魔法段改用物攻、物防及物理判定，转换段伤害乘 1.10。同持两卡时推荐按原始类型各转换一次。需和另一方向一起确认是否覆盖被动、召唤继承和武器触发。 |
| 纯粹主义者 - 术师 | 来源转换。在装备聚合时记录实际装备贡献的攻速点，移除该贡献并折成施法速度和智力。推荐每 1 攻速点对应 1 个施法百分点与 1 点智力。武器固有负攻速及套装、宝石等来源是否一并计算需确认。 |
| 大师铸就 | 来源修正。装备段和卡牌段在生成处保留各自的伤害来源，符合来源的分量单独乘 1.50，再合入命中。这样同一次命中的技能主段和卡牌附段能分别计算。 |
| 狂热者 | 分段被动。每个符合资格的攻击段生成两个稳定子段 ID，沿正式伤害报告提交。需确定总伤害降低 50% 的分摊语义。若两段合计为原伤害的一半，则各为原段 25%。还需确认两段各自的暴击、异常和命中触发资格。 |

### 施放、命中及受击触发

| 卡牌 | 实现与参数 |
| --- | --- |
| 山脉护盾 | 连续脱战 5 秒后给一个独立吸收池，容量为最大生命的 20%。推荐同一次脱战只生成一次，盾可带入战斗直到消耗，下一次脱战满 5 秒补足。用现有 `CombatTiming` 与 `Runtime.absorption`。 |
| 急救用具 | 本人技能与卡牌施加的治疗提高 30%。 |
| 天音爆 | 原治疗有效量严格超过目标最大生命的 20% 时，在目标位置以 3 格为半径产生一次爆炸。推荐用本次实际治疗量作基数，目标再获得 20% 治疗，周围敌人承受 20% 的真实伤害。额外治疗标为衍生事件。 |
| 自适应防护 | 绑定伤害技能。有实效伤害时提高自身物防 20%，持续 8 秒，重复命中刷新。 |
| 蓄力咏唱 | 施法期间按经过时间每秒累计 10% 物攻和魔攻。正常结束、取消、死亡清理。推荐结束帧的释放使用蓄力快照，其他后续行动恢复常规攻击力。 |
| 前进时间到 | 绑定任一非被动技能。施放时提高移速 80%，持续 5 秒，重复施放刷新。 |
| 双重防御 | 绑定伤害技能。有效伤害按最新一次的 5% 重算同一个盾池，持续 3 秒，重复命中刷新期限。 |
| 逃跑计划 | 有效伤害后分别刷新 3 秒移速和盾。移速提高 100%，盾为本次伤害点数的 1%。推荐最近一次伤害重算盾量。 |
| 家园卫士 | 获得 100% 移速。敌方首次造成实际扣血后再持续 5 秒，脱战后恢复。 |
| 终极不可阻挡 | 技能实际放出时获得 350 毫秒无敌，读条技能在读条完成后起算。 |
| 会心防御 | 在本机受伤采用暴击率提供减伤。推荐倍率为 `1 − 暴击率 × 0.65`，例如暴击率 30% 对应 19.5% 减伤。需要确认固定伤害、环境伤害和持续伤害的资格。 |
| 扇巴掌 | 每段对每个敌人的有效伤害叠一层，提高 1% 伤害，上限 25 层，刷新 10 秒期限。 |
| 虹吸 | 绑定任一非被动技能。有效伤害的 1% 用于回血，整次施放共享上限。上限为技能当前等级的基础 CD 秒数对应百分比的最大生命。 |
| 快中求稳 | 位移成功结束后准备一次增益，下一个成功施放的技能取得 80% 伤害增益，并给本人持续 5 秒、容量为最大生命 20% 的盾。推荐按施放快照覆盖该技能所有命中段，并确认何时开始盾计时。 |

### 追加伤害、元素及生成物

| 卡牌 | 实现与参数 |
| --- | --- |
| 闪光弹 | 每次技能在最后一次实际位移结束的位置产生一次 3 格爆炸，物理系数 0.70。 |
| 普攻飞弹 | 在正式普攻周期开始计数，第 4 次从背后产生飞弹，出生点横向扰动 ±0.5 格，向准星发射，物理系数 4.40。复用 `StaffBolts` 的连续碰撞思路，计数使用普攻周期 ID。 |
| 双生火焰 | 命中为火焰异常提供相当于伤害量 100% 的积累。命中前目标已灼烧时追加魔法系数 0.20 的火伤段。推荐同元素本身的积累只计一次。 |
| 冰寒 | 为冻结提供相同的 100% 积累。命中前已冻结时追加魔法系数 0.60 的冰伤段。 |
| 暗影疾奔 | 为侵蚀提供相同的 100% 积累。命中前已侵蚀时追加魔法系数 0.20 的暗伤段。 |
| 极光 | 为感电提供相同的 100% 积累。命中前已感电时追加魔法系数 0.10 的光伤段。 |
| 侵蚀 | 将本人确立的侵蚀升级为 II。保留现有异常积累与恢复，用触发时的强度记录防御倍率，普通目标 ×0.80、强目标 ×0.90。混合积累由哪个来源获得升级资格需明确。 |
| 注魔 | 普攻有效接触追加一段伤害，以物理和魔法攻击较大者作为基数，系数 1.00 并按该攻击类型结算。需确认「攻击最大值」取攻击属性本身还是含力智的面板、同一普攻多段的触发次数。 |
| 俯冲轰炸 | 每次玩家生命代际的死亡只生成一次，以死亡前的最大生命 ×5 作伤害基数，在倒地位置形成范围伤害。需补半径、伤害类型和目标资格。本机死亡与最后出手需要确定提交顺序。 |
| 火绒 | 用局内 7 秒冷却生成半径 2 格的环绕物，沿环绕角度推进并连续检测扫过的目标，命中为魔法系数 1.50 的火伤。需补环绕时长、角速度、同目标上限和撞击后是否消失。 |

四元素卡共用 `ElementAccumulation.addConversion` 的积累来源能力。追加段取各自的物魔与元素抗性结算，原命中快照用于读取既存异常。若要让本次命中刚触发的异常也触发追加段，需要明确改变这一顺序。侵蚀 II 需要让异常系统保存一次触发的实际强度，再由敌人生命维护方应用对应防御倍率。[元素积累](../../src/main/java/cn/yumis/fight/modules/combat/api/ElementAccumulation.java)
