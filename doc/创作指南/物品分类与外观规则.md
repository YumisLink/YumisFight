# 物品分类与外观规则

新增或修改任何物品（注册、创造栏分类、模型与贴图、外观兜底）前必读本文。入口登记见 [项目索引](../README.md)；本文只维护分类与外观规则，不记录具体物品清单。

## 创造栏页签归属

| 分类 | 归属页签 | 判定方式 |
|---|---|---|
| 副职业产出物品 | `AYD-副职业`（`CreativeCatalog.PROFESSIONS`） | 在 `bootstrap/ProfessionItemDisplay.grades()` 登记稀有度即自动归入 |
| 工业材料 | `AYD-材料` | `IndustrialTechnology.materialItem` 判定 |
| 工业设备等 | `AYD-工业` | `IndustrialContent` 登记且非材料 |
| 通货 | `AYD-通货` | `CurrencyRules` 登记 |
| 装备 | `AYD-史诗/神话/太初装备` | `EquipmentTemplates.creative` |
| 其余 | `AYD-其他` | 未命中以上分类的兜底页签 |

副职业产出物品同时从 `AYD-其他` 排除，一个物品只出现在一个页签。**新增副职业物品时必须同步在 `ProfessionItemDisplay.grades()` 补一行稀有度登记**，否则会掉进「AYD-其他」且没有稀有度名与提示。

副职业产出的范围：`ProfessionContent.MATERIAL_IDS`、`CONSUMABLE_IDS`、六档渔获（`FishSpecies`）、六档草药（`HerbSpecies`）、鱼竿、镰刀、48 种炼金药剂（`AlchemyPotions.tiers()`）、三档瓶子、`herb_seed`、`alchemy_cauldron`、`alchemy_wand`。命名前缀沿用 `herb_`、`fish_`、`catch_`、`dish_`、`elixir_`、`potion_`、`rune_`、`ore_`、`hide_`、`ingot_`、`part_`；镰刀、鱼竿、瓶子与炼金设施用具名 ID。

## 外观与贴图要求

1. **禁止注册引用不存在贴图的模型。** 物品没有专属美术时，按本文兜底或复用原版物品模型；不得留紫黑缺失贴图上线。
2. 无专属贴图的草药统一使用**原版草**外观：`items/<id>.json` 引用 `minecraft:item/short_grass`，并照抄原版草物品的 `minecraft:grass` 染色（`temperature: 0.5`、`downfall: 1.0`）。
3. `potion_` 炼金药剂统一使用**原版水瓶**外观：`items/<id>.json` 引用 `minecraft:item/potion`，加常量染色 `4281884102`（原版水瓶蓝 `0xFF385DC6`）。
4. 既有约定保持不变：`herb_seed` 用小麦种子，`elixir_*` 用原版药瓶不染色，其余材料／渔获／菜品／符文沿用各自既有模型。
5. 专属贴图画好后：重建 `models/item/<id>.json` 并把 `items/<id>.json` 指回 `yumis_dungeon_and_fight:item/<id>`；此前被替换的兜底模型不保留占位文件。
