# 贴图创作

## 原版基底

**有原版对应物品或方块时，使用原版同一模型和同一张底图，在原版基础上修改配色与少量材质细节。** 目标是原版材质变体，保留玩家熟悉的外形。

用户所说的“模型”同时包括游戏模型的几何、UV、朝向和显示变换，以及 PNG 内的物品轮廓、比例、构图、分面和像素结构。保留 JSON 文件名或 `parent`，但重新绘制物品形状，也属于改变模型。

| 对象 | 指定基底与保留要求 |
|---|---|
| 桶 | 使用原版 `item/water_bucket.png` 或相应原版桶。保持桶体、把手、桶口和液面轮廓，主要调整液体配色，保留金属桶体的原版明暗。 |
| 金属锭、合金锭 | 使用原版 `item/iron_ingot.png`、`gold_ingot.png` 或 `copper_ingot.png` 中合适的一项。保持锭体形状、斜向朝向、比例、顶面与侧面分界及倒角，只调整材质颜色和局部细节。 |
| 粗矿 | 使用原版 `item/raw_iron.png`、`raw_gold.png` 或 `raw_copper.png` 中合适的一项。保持原有矿粒组合、外轮廓、透明空隙与切面布局，按矿物调整配色。 |
| 粉碎矿（`crushed_*`／粉碎 X 矿） | 统一使用用户选定的 Mekanism `clump_iron.png` 碎块底图。保留颗粒轮廓、大小、组合、透明空隙和明暗结构，按矿物修改配色及局部材质细节。 |
| 矿物粉（现有 ID 后缀 `_concentrate`） | 统一使用 Mekanism 的 `dust_iron.png` 粉末底图，保持原有堆形与像素结构。显示名称使用“山铜粉、钒粉”等“XX粉”形式，物品 ID 和配方沿用原登记。 |
| 其他有原版对应的资源 | 先确定对应的原版物品或方块，沿用其模型、底图和原始像素尺寸，再做材质变化。 |

模型文件仅按需替换贴图引用，保留既有几何、UV、`parent` 和 GUI／手持／展示变换。原版底图的透明边界、画布尺寸、像素占位、主要高光与阴影结构保持一致；局部创作限于原有非透明区域，沿用原版光照方向与像素密度。明确要求设计新模型或新轮廓时，才扩展这些范围。

## 高阶锭的局部创作

沿用同一原版锭形，在已有底色上增加材质特征。T3 使用干净的金属分面与辅色，通过顶面、侧面的色彩和明暗区分材质。T4 可增加双色金属质感，并配合覆盖已有分面的荧光呼吸；普通锭与高纯锭通过配色纯净度、明暗和高光区分。默认不增加划痕、刻线或固定细条光路。用户明确指定的环绕条带按原有分面跨过顶面并接到侧面，色光可在条带内呼吸。外轮廓、原有亮边的位置、主分面关系与模型显示变换保持原样。

蓝紫晶面、深灰与青蓝等强对比材质，通过原图已有明暗色阶映射配色，顶面、侧面和倒角仍由原图的像素角色决定。基础金属保留亮边最亮、顶面亮于侧面的层次，通过整面色温、亮度与宽区域反光增强效果。用户明确要求的晶簇凸起使用顶面内部的高光、晶面和投影表现；夹层配色画在原有侧面厚度内，保留完整顶面、倒角和锭体体积。所有新增细节仍位于原图非透明像素内。

T5 让整锭参与柔和色光变化，增加明显的辅色与荧光感。T6 可参考灾厄宇宙锭的整锭粉蓝变色，显色与退色使用相同时间和互为反向的缓动曲线，亮峰可短暂停留；颜色与光效共用同一强度曲线，避免光效提前消失。动画覆盖锭体已有的非透明像素，每帧仍保持 16×16 和完全一致的透明轮廓，保留原有金属分面与明暗层次。Aseprite 分开保留原版基底、材质配色、整锭色光和柔和荧光图层，按物品命名帧标签导出纵向帧条与对应 `.png.mcmeta`。

指定所有面同步变色时，共用同一色相与时间相位，通过原图明暗区分各面。指定静态配色时，源稿标签只保留单帧，导出时清理旧动画声明；材质参考色与动画是否变色分别按用户要求处理。

指定表面流光覆膜时，本体颜色固定，色膜在独立图层沿原有顶面、侧面与端面连续移动。通过覆膜自身的亮边、收边与独立明暗表现上层镀膜；本体可用较低饱和度的金属色阶及银色亮边表现材质。指定顶面微闪光时，反光跟随覆膜经过顶面的时机出现、柔和退去，并限制在原锭内部。每帧保持约定的覆盖比例，过渡边缘沿金属分面变化，周期末尾接回开头，锭体轮廓和朝向保持。

制作入口为 `tools/draw_industrial_ingot_details.lua`，在现有 `tools/industrial_material_bases.aseprite` 上编辑；基底制作入口完成后也会应用同一细节源。统一导出入口的 `only=ingots` 可仅导出锭类，`item=<已登记物品ID>` 可进一步限定单项；绘制源的临时预览也支持同一 `item` 参数。

## 素材复用

没有原版对应物时，优先复用用户认可的现有贴图，或选择合适的已有素材直接复用；在已有底图上调整配色和局部细节。参考清单中的造型建议也须遵循本页要求。复用外部素材时，在现有资源清单中保留具体来源。

## 作画流程

1. 按上表取得原版或指定模组的底图，核对当前模型与贴图引用；原版资源采用项目对应游戏版本，本机工具入口见 [本机环境](../本机环境.md)。
2. 用 Aseprite 按原始尺寸打开底图，锁定原版基底层，在单独图层做颜色映射与局部材质细节。保留原始透明区域与像素结构。
3. 先制作桶、锭、粗矿等代表物的原版／修改后同尺寸对照，再扩展同系列。对照时确认材质配色有变化、模型与外形一致；模型、轮廓或分面发生变化时，先恢复底图结构。
4. 同步维护可编辑源稿、绘制或导出入口与正式 PNG；仅按需更新贴图路径，保留已有模型和其他任务的资源改动。
