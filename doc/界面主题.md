# 统一界面主题

全体模组界面默认使用已确认的灰色立体风格。菜单、角色、技能、快捷槽选择、装备选择、制作器、工业设备、配方／结构／概率子界面、宝石孔和次元背包共用 `UiTheme`。HUD有独立的高对比度文字／底色角色，也由同一主题文件控制。物品稀有度、元素、技能演出等玩法颜色不改变。

角色属性页右上角提供“暗色模式：开／关”。默认关闭；开启后使用接近原界面的深蓝灰配色，数值保留蓝色粗体。只影响角色属性页，其他页面保持统一灰色。选择保存到客户端设置，关闭界面和重启后保留。

## 修改入口

客户端首次启动生成 `config/yumis_dungeon_and_fight/ui-theme.json`，此后只修改这一处即可。未写的颜色继承默认值；编辑时无需停游戏，每秒检查修改，已打开界面同步更新。JSON错误或非法颜色不会部分套用，继续保留上次有效主题。

- `style`：`beveled` 为灰色立体边框，`flat` 为平面样式。
- `border`：边框厚度1～4像素。
- `textInset`：普通按钮文字左间距2～16像素；装备图标按钮保留必要空间。
- `colors`：使用 `#RRGGBB` 或 `#AARRGGBB`。

主要颜色角色：`PANEL`主面板、`CARD`内容区、`BUTTON/HOVER/SELECTED/DISABLED`按钮、`TEXT/MUTED`正文与次要文字、`NUMERIC`蓝色粗体数值、`BORDER/LIGHT/SHADOW`边框、`SLOT/SLOT_SHADOW/SLOT_LIGHT`凹槽、`SCROLL_TRACK/SCROLL_THUMB`滚动条。

`TIP_*`控制原生深色悬浮框中的文字；`HUD_*`控制战斗HUD，`DAMAGE_BAR`控制橘红输出条。分别设置可保持不同底色上的文字可读。

同一文件的 `characterDark` 对象控制角色暗色样式，可写 `style`、`border`、`textInset`、`colors`；未写的颜色继承暗色默认值及共同角色。旧主题配置没有此对象时仍可直接使用暗色开关。修改暗色配色同样自动刷新。

源码默认值集中在 `src/main/resources/assets/yumis_dungeon_and_fight/ui-theme.json`；运行时的单一修改入口仍是上述config文件。修改字体的玩家入口暂时关闭，默认字体效果保留。
